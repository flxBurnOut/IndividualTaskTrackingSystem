# v1.2.0 新手引导

首次进入面板时，应用窗口变暗并高亮当前讲解的按钮，用简短步骤介绍功能。主窗口左下方及常用对话窗口新增“使用指南”入口。

- 覆盖 14 类主页面和常用窗口：总览、今天、项目与课程、每日复盘、每周回顾、设置的五个页面，以及手动计划、Codex 讨论、每周课表和事项编辑。
- 支持上一步、下一步、跳过本页、关闭自动介绍和随时重看。已完成或跳过的面板在重启后保留进度，各数据空间分别记录。
- 等待页面加载时如已开始操作，会取消这次自动介绍。切换窗口或关闭面板时安全中断，保留未保存内容。
- 引导期间拦截底层点击和快捷键，避免误保存或误发送。滚动区域内的控件先定位到可见位置，结束后恢复滚动位置；适配浅色、深色和大字号。
- 说明与真实行为一致：今天页的反馈立即保存，复盘页的选择需要确认；Codex 协助说明会随处理方式变化。

本版继续使用原数据目录及升级快照机制，个人课程、任务、计划、材料、反馈和会话关联保持在原数据空间。已有用户升级后首次进入尚未介绍的面板，也会看到引导，可随时关闭自动介绍。

升级前保存工作，通过“版本与更新 → 退出并准备更新”退出旧软件及后台，运行新安装包时核对原程序目录和数据目录。文件被 Codex 接口占用时，待任务完成后暂时退出 Codex 再安装。

引导只覆盖软件窗口，不遮挡其他应用。托盘后台状态与 Codex 连接状态分别显示；本版未增加 Windows 登录自动启动。
