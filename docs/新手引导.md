# 新手引导

本功能从 1.2.0 开始提供，升级后第一次进入未介绍过的面板时也会显示。

第一次打开界面时，应用窗口会变暗，高亮当前讲解的按钮或区域。说明卡显示步骤进度，可以上一步、下一步、跳过本页或关闭自动介绍。引导只覆盖本软件窗口，不遮住其他应用。

首次进入以下面板时，会显示对应的简短介绍：

- 总览：导航、新建、搜索、设置、版本与后台退出、使用指南。
- 今天：日期、手动安排、Codex 计划、即时反馈、习惯与课表。
- 项目与课程：目录、归属、任务和资料。
- 每日复盘与每周回顾：选择结果、确认保存、已保存的周汇总。
- 设置中的日常习惯、显示、课表、Codex 协助、数据与高级。
- 手动计划、Codex 讨论、每周课表和新建／编辑事项窗口。

“跳过本页”和完成介绍都会记住当前面板，不会影响其他面板的首次介绍。主窗口左下方的“使用指南”可以重看当前面板、重新查看入门导览，或切换“自动介绍新面板”。对话窗口也有“使用指南”按钮。关闭自动介绍后，仍然可以手动查看。

引导期间，高亮区域的鼠标点击和底层快捷键都不会执行业务操作。Tab 在引导按钮之间移动；Esc 跳过介绍，保留当前窗口和未保存内容。等待面板加载期间，如果已经开始操作，就取消这次自动介绍，避免中途打断编辑。

已看过的面板和自动介绍开关保存在当前数据目录的 `ui-onboarding.json`，与课程、任务、计划和反馈分开。正常升级并沿用数据目录后会继续保留；不同数据空间分别记录。引导不会创建任务、发送 Codex 请求或自动保存表单。

## 验收步骤

1. 在新的测试数据空间打开软件：看到全窗口暗遮罩、按钮高亮和步骤进度；依次前进、返回、结束。
2. 进入上述各个面板：首次有介绍；完成或跳过后，再进入、重启软件都不重复。
3. 在“使用指南”重看当前页，再关闭自动介绍：新面板不弹出，手动查看仍可用。
4. 在表单内填写未保存的内容，再手动打开引导：高亮位置点击不保存；按 Esc 后表单保持打开、内容仍在。
5. 切换浅色、深色和大字号，并调整窗口大小：文字可读，按钮可用，高亮跟随控件。
6. 关闭正在介绍的窗口、打开其他对话窗口或快速切换页面：不遗留遮罩，不抢回焦点，不意外执行保存或发送。
