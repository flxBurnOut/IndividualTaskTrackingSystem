# 个人事务管理 1.3.5（本地验收候选）

本候选扩展普通 MCP 客户端接入，并加强多个入口共用业务服务时的繁忙处理与恢复。尚未发布或安装到日常正式环境。

- 设置新增“助手连接”，提供 Antigravity、通用 JSON 和 Codex TOML 的预览、复制、受保护合并与 MCP 自检。名称、提示和数据校验按程序通道区分，正式版沿用用户原数据选择，Beta 继续完全隔离。
- 每个 MCP 客户端使用独立进程，共用所属数据空间的业务服务。Antigravity/通用连接只开放普通业务与上下文工具；原 Codex 受管会话规则保留。
- 繁忙时返回明确的未受理响应，客户端在原超时预算内有限重试；请求编号、输入快照和版本条件不变。未知写入结果继续查询原回执，避免重复保存。
- 保留 1.3.4 的普通续读、批量资料读取、批量检查点、来源定位与业务版本校验，没有业务数据结构迁移。
- 安装使用前需同时更新 GUI、后台和 MCP；新版启动先核对稳定通道、版本与原数据身份。既有配置和原文件保留，不迁入 Beta 数据或生成演示库。

最终验收结果见开发交接。当前包只供本地审查，不代表 Windows 分支已合并或日常程序已升级。
