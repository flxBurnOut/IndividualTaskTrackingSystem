# 个人事务管理 1.3.0

本版将已在 Beta 完成的手动操作与界面改进纳入正式版，继续使用原正式数据空间。

## 新增与改进

- 独立任务池、快速记录、手动单日计划草稿、依赖编辑、批量录入与任务拆分；保存前核对预览。
- 日常习惯独立入口、顶部搜索、任务保存后的查看入口、无计划时的实际反馈与回顾。
- 五处图表可选择显示方式，明暗模式与强调色独立保存；同字段冲突保留当前输入，无关修改不会覆盖其他设置。
- 统一当前界面，改善窄窗、大字体、中文文字布局、按钮换行与页签切换，修复项目/课程切页闪窗；旧界面开关退役，旧偏好文件保留。
- 修复新手引导首次显示、弹窗定位和滚动避让；指引本身不执行业务操作。
- 保留 1.2.1 的资料分类归档和移动原件，资料编号、关联和内容校验保持不变。

## 更新与数据

更新前保存编辑，等待任务完成，在“版本与更新”准备退出后台。安装时继续选择原数据位置，无需重新导入。已有记录、资料原件、设置和会话关联继续使用；数据库升级前自动保存可恢复快照。

正式版显示“个人事务管理”，后台通道为 `stable`。Beta 独立工作树、演示数据、窗口和服务保持独立；正式版不会打开 Beta 数据目录或执行演示生成。软件入口、后台与 MCP 均需核验为 1.3.0，旧 MCP 连接需在任务空闲后刷新。

本地发布文件位于 `release/PersonalManagement-1.3.0/`；`app/` 保存程序，外层保存安装包、校验值和清单。同版本产物不覆盖重建。

## 保留的边界

本版没有新增外部助手供应商，也未实现跨多天计划的一次原子保存。候选回执、实际写入与明确反馈仍按既有规则处理。Beta 的完整独立安装渠道仍属后续工作。
