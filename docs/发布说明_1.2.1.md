# v1.2.1 资料分类归档修复

导入课程或项目资料时可以明确选择分类子目录。资料保存后显示实际位置，避免把“已保存”误认为“已按分类归档”。拖入文件使用相同的选择流程。

- 新增“移动原件…”和业务接口 `refile_source`，同步更新原件位置与索引，保留资料编号、校验值、提取记录和已有引用。
- 新增 `library_destinations` 查询；`add_source`、`import_asset` 支持 `library_subdir`。归属已有分类目录却未指定位置时要求明确选择，空字符串表示根目录。
- 重复导入到不同目录时给出原资料及当前位置，不静默移动或制造重复记录。
- 不覆盖目标位置的不同内容；保留仍被引用或已被修改的旧副本。清理失败可按原请求编号重试，断线后不会换一个请求重复归档。
- 新接口沿用普通 MCP 与受管讨论的权限边界。受管讨论不能借移动文件绕过核对流程，可使用客户端界面整理。

本版不更改任务、计划或完成反馈。继续使用原数据目录；发布包不包含个人资料。本地应用本修复前须完成软件及后台版本切换，原 MCP 连接重新加载后才会暴露新接口。

升级前保存工作，通过“版本与更新 → 退出并准备更新”安全退出旧软件及后台。安装时核对原数据目录；不要将个人数据复制进程序目录或重新导入。
