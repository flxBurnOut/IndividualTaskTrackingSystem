# 会话、数据空间与原文件目录

适用于个人事务管理 v1.0.1。程序、业务记录、Codex 会话与资料版本各自有明确位置；升级程序不要求重新迁移业务数据。

## 程序和数据分开

安装器默认把程序放在 `%LOCALAPPDATA%\Programs\PersonalManagement`，默认数据目录为 `%LOCALAPPDATA%\PersonalManagement\data`。也可选择其他已有数据空间。

一个数据空间主要包含：

| 内容 | 作用 |
| --- | --- |
| `database.sqlite3` | 任务、计划、反馈、来源关系、会话关联、作业及业务回执 |
| `Codex事务助手` | 该空间的固定 Codex 项目及受管理接口配置 |
| `原文件` | 可浏览的资料副本，按登记的归属和相对目录组织 |
| `blobs` | 内部不可变内容版本，按内容指纹复用 |
| 运行状态文件 | 本机服务发现和连接信息，不是可分享的用户文档 |

第一次打开新的空目录会建立空库；选择已有目录会读取其记录，不自动合并另一个空间。现有用户升级后用“为已有数据创建快捷方式”或包内“创建快捷方式.vbs”绑定原目录，随后使用该快捷方式。普通卸载保留数据。

“选择数据空间”和 `--choose-data` 只影响本次启动，不永久改写默认快捷方式或默认数据目录。

不要把程序目录、某次安装包目录或下载文件夹当成已有数据目录。当前所用位置可在“设置 → 数据与高级”查看。

## 固定项目与事项绑定

启用 Codex 协助并连接后，软件准备当前数据空间的“Codex事务助手”项目。普通启动的 Codex 可被自动发现，无需专用启动模式。

软件发起的讨论按明确范围保存：

- 某日计划绑定该日计划事项。
- 某日复盘绑定该日复盘事项。
- 课程或其他对象讨论绑定对应业务对象。
- 日常讨论保留自己的范围。

同一事项继续原会话，不凭标题或创建日期查找一个看起来相似的聊天。聊天里的业务日期与聊天创建时间不是同一个概念；标题也不是关联依据。

从旧日计划会话继续提问，仍属于原日期。若要处理另一日期，应从“今天”选择该日期打开；不要只改消息里的日期就当作已经切换范围。数据空间或对象归属不一致时，软件保留历史并提示核对，不自动换成另一事项。

软件窗口中的“在 Codex 查看”打开该事项已经关联的会话。普通重连不会再发旧消息，关闭讨论窗口也不代表取消桌面正在处理的回合。

## 两种保存路径

**受管事项讨论**通过业务接口返回候选，由用户在软件中核对后采用。可以从软件或其关联的 Codex 会话继续；结果仍回到原事项。发送下一条消息会使未采用的旧候选失效，但不撤销此前已经保存的业务变更。

**普通、未绑定事项的项目对话**适合处理新通知、临时信息或跨事项整理。它按用户明确要求直接调用共享业务接口保存，不需要继承某段旧聊天的记忆。只讨论或分析时不保存猜测。

两类对话共享已经保存的业务事实，不自动镜像或合并全文。归属由服务读取真实调用身份确定；历史绑定失效不能被当成普通可写对话使用。

## 查看和更新原文件

课程或项目首页点“打开文件夹”，单个资料可点“打开原文件”。设置的数据页也能“打开原文件目录”。

通过“添加资料或通知”导入文件、文字、截图或网页快照时，软件登记来源并保存托管版本。可浏览副本保留合适的文件名与相对归属；同名不同内容分开保存。相同内容在内部按指纹复用，不需要给每个日期复制整份原件。

可浏览原件是独立副本，默认只读，不是可写地链接到内部不可变存储。另存或编辑后，应重新导入，才成为新的业务资料版本；不会因此静默改写旧笔记、反馈或已采用依据。

可浏览副本被移动或删除后，可再次打开或准备所属文件夹，按内部登记版本重建。软件不会自动覆盖已编辑的副本。内部版本也已丢失时，不能凭数据库条目恢复不存在的内容。

旧版只有外部路径的引用会明确保留引用性质；需先“保存到软件”才能获得托管副本保护。

## 备份、恢复与移动

软件备份包含业务数据库和已登记的托管原件及衍生版本。恢复时可按登记路径重建可浏览目录。仅在文件夹中新增、没有导入的额外文件，不属于已登记资料备份；只有外部路径的引用也不等于已经备份外部原件。

“恢复备份到新目录”保留当前空间，不覆盖原数据。恢复后的数据身份变化，旧候选失效，原提醒及准备规则暂停，需核对后重新启用。模型连接也需重新核对，不能把另一个空间的运行状态文件视为有效连接。

移动数据空间与升级程序是不同操作。移动前应保证没有正在写入的业务服务，并核对托管资料完整性；移动后从新位置打开，检查项目和会话关联。路径或数据身份不一致时不承诺自动继承全部旧模型连接。直接在运行中复制 SQLite 文件不等于已经制作一致备份。

## 分发边界

应用发布包不包含用户数据库、课件、账号或聊天历史。固定项目内的实际配置、运行状态和个人资料属于本机数据，不作为软件模板公开提交。

详细操作见[使用说明](使用说明.md)，连接协议与候选边界见[Codex 接口](Codex接口与后台推理.md)。
