# v1.0.0 发布说明

个人事务管理的首个用户发布版本。该版本沿用已冻结的日常业务与连接功能，完成版本、安装包和通用文档整理，不新增业务能力。

## 下载与安装

从 [v1.0.0 Release](https://github.com/flxBurnOut/IndividualTaskTrackingSystem/releases/tag/v1.0.0) 下载：

- `PersonalManagement-1.0.0-Setup-x64.exe`
- `SHA256SUMS.txt`

仓库当前为私有仓库，下载需要相应访问权限。

安装器面向 Windows x64，按当前用户安装。程序默认位置为 `%LOCALAPPDATA%\Programs\PersonalManagement`，业务数据默认位置为 `%LOCALAPPDATA%\PersonalManagement\data`。首次使用新空目录会建立空数据空间；不自动迁移、重置或重新导入已有数据。

已有用户使用“为已有数据创建快捷方式”或包内“创建快捷方式.vbs”，选择原目录后从新建快捷方式进入。“选择数据空间”只影响本次启动，不永久切换默认安装快捷方式。

升级若遇到程序文件占用会提示处理，不强行终止进程。普通卸载保留业务数据。本版本未签名，Windows 可能显示来源或发布者提醒；请核对下载来源及随附文件校验信息。

## 首发功能

- 课程、项目、任务及归属管理，已完成记录，任务删除与撤销。
- 手动每日计划和 Codex 计划候选，固定日程、容量与历史反馈保护。
- 每日复盘、出勤与每周回顾，补课补欠及独立数量进度。
- 每周课表、教学周与 Recess 设置、单次停课或改时间。
- 准备待办、提醒、安排习惯与提前警戒。
- 托管资料、原文件目录、长资料分批处理、笔记整理、备份和恢复。
- 普通 Codex 任意启动顺序连接，同事项原会话续聊、候选回传和按身份恢复。

软件关联会话返回候选，用户确认后写入。普通未绑定项目对话按用户明确授权调用同一业务接口直接保存。模型文字不是业务回执。

## 已知边界

- Codex 桌面共享依赖版本相关私有接口。桌面更新可能需要后续适配；不兼容时明确停止，不自动换用隐藏后台。
- 每日计划入口绑定所选日期，没有独立的多日排程窗口。普通 MCP 对话可以逐日处理一段时间，多个逐日保存不是单次原子事务。
- 新消息会使同事项未采用候选失效。取消或异常后是否可恢复取决于原身份、检查点和当前状态，不保证所有失败都可无条件续接。
- 长资料按批继续读取，不再限制整份8页，但不承诺任意格式、图表和附件都可完整解析。
- 课表单次例外只支持原系列同星期的日期；周视图暂没有独立 Recess 周标签。
- 高级成果生成及采纳主要通过业务接口使用，没有完整独立 GUI。
- 提醒依赖本机业务服务运行，电脑睡眠或关机时不执行；没有 Windows 登录自启动或外部聊天推送保证。
- 完成、出勤、提交、掌握与实际用时分别保存，未知不自动推断。

用户已完成当前日常使用体验验收并同意首发。该结论不等于全部人工检查项、所有设备组合或长期运行场景均逐项通过；后续问题按实际证据继续修复。

完整说明见[使用说明](https://github.com/flxBurnOut/IndividualTaskTrackingSystem/blob/v1.0.0/docs/使用说明.md)及[Codex 接口](https://github.com/flxBurnOut/IndividualTaskTrackingSystem/blob/v1.0.0/docs/Codex接口与后台推理.md)。
