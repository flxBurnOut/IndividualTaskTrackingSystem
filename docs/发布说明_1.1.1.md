# v1.1.1 Windows 后台托盘

关闭主窗口后，Windows 通知区域继续显示“个人事务管理”图标，用户可以直接查看后台状态、重新打开窗口或正常退出后台。

- 图标悬停提示与右键菜单显示后台运行状态，以及执行中、排队和待核对的任务数量。后台失联或停止时会明确显示。
- 双击图标或选择“打开个人事务管理”恢复窗口。同一数据空间只打开一个主窗口；再次点击快捷方式或托盘会转到已有窗口。
- 右键提供“版本与更新”“检查后台状态”和“退出软件与后台”。普通关闭主窗口继续保留后台；明确退出会检查活动任务、保存回执及打开的编辑窗口，不强制丢弃工作。
- 正常退出后暂停自动拉起后台，重新打开软件才恢复。准备更新时，后台和托盘也会正常退出，释放程序文件。
- 后台单独通过 MCP 启动时也会显示托盘；托盘与主窗口相互独立。观察进程意外退出后，运行中的后台会重新建立托盘。

Windows 可能将新图标收进任务栏的“显示隐藏的图标”区域。可将其拖到任务栏常显位置。每个打开的数据空间有自己的图标，悬停提示和菜单显示数据位置。

本版继续使用原数据目录及升级快照机制。没有增加 Windows 登录自动启动，也不会在电脑关机或睡眠时执行任务。
