# 个人事务管理 Beta 使用说明（基于 v1.2.1 源码）

本软件在本机保存课程、项目、任务、计划、资料和执行反馈。日常入口是“总览”“今天”“任务”“项目与课程”“复盘”。助手为可选能力；手动记录、安排与复盘不需要模型连接。

本页的手动体验改造说明对应 Beta 当前开发源码，不代表正式版或已安装程序已更新。Beta 使用自己的启动入口、后台和资料库；安装升级部分仍以已发布版本为准。

## 不连接助手也能开始

1. 在“任务”输入标题，点击“记下任务”或按 Enter。这里先记录，不自动安排日期；日期、所属位置、预计用时和完成条件都可以稍后补充。
2. 一级页面只显示记录入口和本次最近记录的少量任务。要查找、整理或编辑所有任务，点击“查看任务库”，进入第二级页面。保存后也可用“查看刚记录任务”直接打开新任务。
3. 记录成功后点“加入今天”；也可以进入“今天”，在顶部写下任务并点“添加到 M 月 d 日”。已有任务使用“从已有任务选择…”，包括未填写日期的任务。需要详细排序或排时，再打开“详细安排…”。
4. 没有事先安排计划，也可到“复盘”选择“记录实际情况”或写文字小结。软件保留无原计划的事实，不补造计划或完成率。
5. 在左下角“日常习惯”设置每天最多安排多久、不排任务的时段、日期提醒及安排习惯；在课程内直接维护评分项、笔记和日程。

新数据空间默认隐藏助手入口。左下角始终保留“Codex 协助”，其中“在各面板显示助手操作入口”可按需开启或隐藏，点击“保存入口显示”应用；它与“允许软件使用本机 Codex 辅助处理”分别保存，打开页面或显示入口不会启用助手。隐藏不会关闭后台、取消正在处理的任务或丢弃候选；主窗口仍会保留待处理结果入口。旧数据中已启用的助手入口会继续保留，直到用户明确关闭显示。

## 记录任务与查看任务库

侧栏“任务”首先打开记录页，不直接展开整个任务库。“本次刚记录”最多展示五项，可继续输入下一项，也可打开任务或将它加入今天。重新进入完整任务库使用“查看任务库”；任务库顶部“返回记录任务”可回到轻量入口。

任务库中的**查看条件决定显示哪些任务，排列顺序决定这些任务先后怎么排**。这些操作只改变列表，不修改任务的内容、完成状态或安排。

| 查看条件 | 含义 |
| --- | --- |
| 未完成任务 | 尚未明确记录完成的有效任务。 |
| 任务未填日期 | 没有填写任务的希望处理日期和截止日期；它仍可能已经加入某一天的安排。 |
| 今天到期或日期已过 | 截止日期为今天或更早、尚未完成的任务。 |
| 以后到期 | 截止日期晚于今天、尚未完成的任务。 |
| 未分类任务 | 尚未设置所属位置的未完成任务。 |
| 已完成任务 | 已有明确完成记录的任务。 |
| 全部有效任务 | 包括未完成和已完成，不包括已删除、已取消或草稿。 |

“任务名称”在当前查看范围内搜索，覆盖全部分页。“所属位置”可限定某个项目、课程等位置及其下属任务。列表上方会说明正在查看的范围和找到的数量；没有结果时，可清除搜索词、位置条件，或点“清除查看条件”重新查找。

“排列顺序”可选最近记录优先、截止日期从近到远或按所属位置排列，作用于全部查询结果，不只是当前页。截止日期排序中，未填日期的任务排在有日期的后面。底部显示当前第几项、共多少项，以及上一页和下一页。

单击选中任务，可以看到它的完成条件；“打开任务”、双击和 Enter 都打开完整详情。“编辑…”修改内容，“拆成几个小任务…”进入拆分窗口。“加入今天”和“标记完成”是独立操作：前者加入安排，后者记录今天的实际完成结果。完成任务不代表参加课程、提交成果或掌握知识。打开详情或编辑后返回，原查看条件、分页、选中任务和列表位置会保留。

## 使用指南与首次介绍

自动介绍开启时，首次进入主界面会等待初始资料加载且窗口获得焦点，再显示入门引导。开始输入会取消本次自动提示；已完成、跳过或关闭自动介绍的选择会保留。稍后可从左下角“使用指南”重看当前面板或入门导览；独立窗口右上角也有“使用指南”。例如 Codex 面板已完成过四步介绍，重新打开不会强制重播，可用该按钮重看。

引导高亮当前实际控件，必要时自动滚动；窗口移动、缩放及字号改变后会跟随调整。退出时恢复原滚动位置。点击引导的下一步不会执行高亮按钮或保存业务内容。

## 一次添加多个任务（开发源码）

在“任务”记录页点击“一次添加多个任务…”。这是**一次记录多项任务**，保存后不会自动加入某天的安排。每批最多 50 项。

1. **写下任务。**每行一件事，例如三行分别写“整理阅读笔记”“购买活动材料”“联系场地负责人”。点击“下一步：核对任务”。
2. **核对任务与保存位置。**清单里每项都是即将建立的任务，目前尚未保存。可直接改名称，点“补充信息”填写完成条件、预计用时、截止日期等；未知内容留空。“再添加一项任务”增加一项，“从本次清单移除”只移除此窗口的未保存条目。修改后点击“核对修改”，核对通过后才能保存。
3. **保存并查看结果。**点击“保存这 N 项任务”。成功后显示本次保存的任务，可用“查看这批任务”进入任务库，或点击“安排这些任务…”打开安排流程。

“这批任务放在哪里？”是选择这些任务的共同所属位置，可以暂不分类，也可以选择项目、课程、分类、活动或另一任务。选择器显示类型和完整路径，用来区分同名的位置。本批使用同一位置；需要放到不同位置时分批记录。

普通输入无需理解表格格式。已有 Excel 等表格内容时使用“从表格粘贴…”：按任务名称、完成条件、预计分钟、截止日期、希望处理的日期五列粘贴，不带表头，日期使用 `YYYY-MM-DD`。**希望处理的日期只让任务成为当天候选，不等于加入每日安排**。窗口的“如何一次添加？”提供完整例子和保存位置说明。

整批成功或整批不写入；其他窗口修改数据后，可能需要重新核对，输入继续保留。保存结果暂时无法确认时，使用“核对上次保存结果”，沿用原请求核对，避免另建一批。成功后可逐项编辑或删除，暂不提供整批一键撤销。未提交内容不是跨重启草稿，关闭前会提示是否放弃。

## 把大任务拆成子任务

在任务库选中任务，点“拆成几个小任务…”，也可从任务详情的拆分入口进入。窗口先显示原任务及已有子任务信息，再填写至少两项子任务；每项都需要“要做什么”和“做到什么算完成”。“添加子任务”增加一项，“移除这个子任务”移除本次未保存的条目。

例如，把“准备阅读角活动”拆为：

- 确认场地：取得负责人确认。
- 准备材料：清单中的材料全部齐全。
- 布置现场：按活动清单检查通过。

子任务是能独立打开、安排和记录完成的真实任务；任务内部的普通清单项只是核对要点，不会自动建立为子任务。已有子任务不会被替换，重复拆分会继续新增。

默认“这些小任务可以分别进行”，不额外建立它们之间的依赖。如果确实有先后要求，选择“需要按顺序进行”，检查窗口中的箭头方向；这里建立的是前后依赖，不只是列表排序。子任务仍继承原任务已有的前置要求，原来的后续任务继续依赖原任务。

点击“核对子任务”，核对通过后保存。原任务、已有计划、反馈和完成条件保持不变。**全部子任务完成后，原任务仍需单独确认完成**。原任务的补课范围和累计进度不会自动分摊到子任务。保存后可返回原任务查看子任务；窗口“如何拆分？”提供同一例子、子任务与清单项的区别及依赖说明。

## 安装、升级与数据位置

以下安装说明针对正式发行版；Beta 使用独立源码入口。正式版首次使用运行已发布的 `PersonalManagement-1.2.0-Setup-x64.exe`。程序默认安装到 `%LOCALAPPDATA%\Programs\PersonalManagement`，数据默认放在 `%LOCALAPPDATA%\PersonalManagement\data`。安装器按当前 Windows 用户安装，并显示本次使用的数据位置。

打开新空目录会建立空数据空间。已有用户在安装器中核对原数据目录，无需把数据复制进程序目录或重新导入。升级优先继承已保存的数据位置；从旧版升级时，也会尝试读取已有软件快捷方式。无法确认或多个入口指向不同空间时，必须选择要继续使用的目录，不会静默猜成默认空空间。便携版用户可安装到独立程序目录并选择原数据位置；旧便携程序文件不会被自动删除。

“选择数据空间”入口或 `PersonalManagement.exe --choose-data` 只改变本次打开的目录。需要长期使用另一目录时，通过“为已有数据创建快捷方式”创建绑定该目录的快捷方式；已登记的安装版会同时记住该位置，供下一次升级延续。选择目录不会合并或重置已有内容。一个安装版的主快捷方式绑定一个空间，其他空间仍保留，可另建快捷方式。

升级操作：

1. 在主窗口打开“版本与更新”，核对软件版本、后台版本和数据位置。保存并关闭其他编辑窗口，等待后台及 Codex 任务结束。
2. 点击“退出并准备更新”。有任务、导入或保存正在执行时会拒绝退出；安全退出后，后台保持暂停，避免 MCP 自动把旧服务重新启动。如果取消升级，重新打开管理软件即可恢复使用。
3. 运行新版安装包，核对程序目录和数据目录。已登记的安装版使用原程序目录替换程序，个人资料保持在原数据目录。若 Codex 仍加载着此目录中的 MCP 程序，安装器会提示占用；请先结束任务并暂时关闭 Codex，再继续安装。安装器不强制关闭程序。此限制针对替换正在使用的程序文件，日常连接仍支持任意启动顺序。
4. 从更新后的快捷方式启动。旧数据库先进行完整性检查和升级前快照，再在一个事务中更新结构；失败则回滚此次结构更新，保留原记录。课程、任务、计划、反馈、设置、材料和会话关联继续使用。启动后可在“版本与更新”重新核验。
5. Codex 接口需要重新加载后才会获得新工具。新版服务会拒绝旧入口继续执行操作；页面分别展示后台版本和最近一次 MCP 请求的版本，不把写好配置或桌面连通当作所有会话均已刷新。

1.0.x 没有“退出并准备更新”入口。首次从这些版本升级时，关闭窗口后仍可能有旧后台进程。应先结束任务并退出旧软件及其后台；若无法正常退出，可在下一次 Windows 登录后、启动两端之前安装。之后的升级可使用新的准备更新入口。

升级快照位于原数据目录的 `upgrade-backups`，只包含数据库及核验记录；资料文件留在原位置，并不是每次复制所有附件。需要完整业务备份时，先使用“设置 → 数据与高级 → 创建并核验备份”。不会自动用旧快照覆盖用户后续新增记录。数据库被较新版本打开后，不支持直接使用旧程序降级；如需恢复，保留当前空间，并将合适的完整备份恢复到独立目录。

普通卸载保留业务数据及升级快照。安装器只管理自己的程序文件，不清空未知目录。本版不自动下载更新，需运行从可信来源取得的新版安装包。

本版本没有代码签名，Windows 可能显示来源或发布者提醒。请核对下载来源及文件信息。

## 新手引导与使用指南

首次进入总览、今天、任务、项目与课程、每日复盘、每周回顾、设置各页，以及手动计划、Codex 讨论、课表和事项编辑窗口时，会用暗色遮罩高亮常用入口，逐步介绍功能。引导只覆盖软件窗口。

介绍卡支持上一步、下一步、跳过本页和关闭自动介绍；按 Esc 可跳过并保留当前编辑内容。引导拦截底层点击和快捷键，不会替你保存、发送或修改业务记录。进入面板后已经开始操作时，会取消该次自动介绍，避免打断编辑。

主窗口左下方“使用指南”可以重看当前面板、查看入门导览和切换“自动介绍新面板”；常用对话窗口也有“使用指南”按钮。完成与跳过按面板记住，重启后沿用。进度保存在当前数据空间，正常升级不会清空；关闭自动介绍后仍可手动查看。滚动区域内的按钮会先滚到可见位置，结束后恢复原滚动位置。

## 关闭窗口、后台状态与退出

关闭主窗口后，后台继续运行，Windows 任务栏右下角的通知区域保留“个人事务管理”图标。如果未直接显示，请打开“显示隐藏的图标”；也可将图标拖到任务栏常显位置。

- 悬停或右键查看后台是否运行，以及执行中、排队、待核对的任务数量。灰色图标与文字提示表示后台未运行或状态暂时无法确认；后台运行不代表 Codex 桌面也已连接。
- 双击图标或选择“打开个人事务管理”重新打开窗口。重复打开快捷方式会转到已有窗口，同一数据空间不重复开窗。
- “版本与更新”打开升级入口；“检查后台状态”立即重新核验。多个数据空间各有图标，菜单显示对应的数据位置。
- “退出软件与后台”检查尚未结束的任务与保存操作。存在未保存的编辑窗口时会提示先保存；不会强行终止任务或丢弃编辑。成功退出后图标消失，后台保持暂停，重新打开软件可恢复使用。

后台通过 Codex 的 MCP 接口单独启动时也会显示图标。托盘意外退出后，运行中的后台会重新建立图标。本功能不提供 Windows 登录自动启动；电脑睡眠或关机期间不会执行任务。

## Antigravity 与其他 MCP 助手（Beta 源码）

在“设置 → 助手连接”选择 Antigravity、通用 MCP 或 Codex。页面显示当前 Beta 数据空间，配置由当前 Beta 程序生成，不读取或复制正式版的服务令牌、数据或连接配置。每个数据空间使用独立的 `personal_management_beta_…` 名称，避免与已有正式版条目重名。

1. 点击“复制配置”，或从 Antigravity 的 MCP 设置打开原始配置，选择其实际使用的 `mcp_config.json`。
2. 点击“预览合并”，核对目标路径与新增连接；点击“写入这项连接”后，保留其他服务器与设置，并保存首次合并前的 `.personal-management-beta.bak` 备份。相同配置重复保存不改文件，同名不同内容、预览后被修改或另一个窗口正在写入时会停止。`.personal-management-beta.lock` 是本机配置写入锁，不是业务数据。
3. 含注释、尾随逗号等非标准 JSON 的文件暂不自动合并；原文件保持不动，可复制本连接条目手动添加。通用 JSON 是启动参数模板，不代表每个客户端使用相同的配置字段。Codex 仍可使用原“Codex 协助”页管理的专用项目，无需重复添加。
4. 点击“检测 MCP”验证本系统生成的启动命令、协议握手、工具列表和业务状态读取。自检可能按需启动该 Beta 空间的独立后台，不修改业务记录、不调用外部模型。自检通过不代表 Antigravity 已加载配置。
5. 在外部助手刷新 MCP，再让它读取当前状态，确认数据空间和通道为 Beta。Antigravity 与通用连接只提供普通业务工具，暂不提供受管会话绑定、候选回传或软件主动派发。

多个助手各自运行 MCP 入口，连接同一 Beta 空间的单个业务服务；正式版仍独立运行。服务忙时会返回明确结果并有限重试。写入返回不确定时，保留原请求编号查回执；版本冲突时重新读取并核对，不能直接覆盖另一入口的修改。

这批源码新增了后台能力校验。若提示旧 Beta 后台能力不匹配，先保存 Beta 工作，等待其作业结束，再通过 Beta 托盘正常退出后台，并从本 Beta 工作树启动。外部助手的 MCP 也需重新加载；无需操作正式版。

命令行也可输出配置或自检，以下均在 Beta 工作树运行：

```powershell
.\.venv\Scripts\python.exe -m management --data-dir .beta-data/default --mcp-config antigravity
.\.venv\Scripts\python.exe -m management --data-dir .beta-data/default --check-mcp antigravity
```

Antigravity 的配置格式和入口以其[官方 MCP 文档](https://antigravity.google/docs/mcp)及本机版本为准；本功能不改变客户端账户、模型或授权设置。

## 第一次连接 Codex

1. 在本机安装当前 Windows Codex，并自行完成登录。
2. 点击左下角“Codex 协助”，启用协助，选择“在 Codex 桌面同步显示”，按需要选择模型，然后点“保存 Codex 协助设置”。程序路径和等待时长可在“高级连接选项”中调整。
3. 点“连接 Codex”。软件核对专用项目和业务接口，并连接正常启动的 Codex。已有明确拒绝信任或自定义配置冲突时，会提示核对，不覆盖你的选择。
4. 以主窗口、设置页和讨论窗口共用的实时状态为准。“项目已准备”或过去连接成功不等于当前已经连接。

日常可按任意顺序启动管理软件和普通 Codex。任一端关闭后重新打开，软件会重新检查连接；不需要每次切换启动模式，也不应靠反复重启解决普通断连。

Codex 未打开时，自动状态查询不会反复把它拉起。明确点击“连接 Codex”或“连接并发送”时，软件才可通过 Windows 正常入口打开当前 Codex。连接恢复不自动重发旧消息。

“连接并发送”只保留本次点击时的草稿。等待期间修改文字、改变附件、关闭窗口、取消等待或等待超时，都会撤销这次待发送动作。之后需要按当前内容重新明确发送。

也可选择“仅在管理软件中处理”。这是独立处理方式，不保证回答实时出现在当前 Codex 桌面，不是桌面连接失败时的自动替代方案。

## 建立课程、项目和任务

在“＋ 新建”选择类型：

- 课程填写名称、可选代码和说明。未知学期日期留空；没有第一教学周依据时不猜周号。
- 项目填写目标和验收条件。在项目内添加子项目时，界面会显示所属父项目。
- 任务填写具体工作、完成条件、可选估时和日期。任务可属于课程或项目，也可独立存在。
- 分类是可选的长期整理方式，例如学习、健康、职业，不等于一个待完成任务。

打开课程或项目后，可在“实际任务 → ＋ 添加任务”新增。任务编辑中“所属位置”可以选择课程、项目等位置或清除位置；项目目录拖动仍可作为快捷操作。非法类型、自己或自己的下级不能成为新位置。任务内容和位置分别保存；如果内容已保存而位置变更未成功，窗口会明确说明并保留尚未完成的位置修改。

任务窗口的常用字段不再要求先勾选启用。截止日期和预计用时显示为紧凑属性，例如“截止日期：未设置”“预计用时：未估计”，点击属性展开填写。已有值直接显示在属性文字中；“清除日期”或“清除”表示明确移除该值，“未估计”与零分钟不同。打开日历本身不代表确认了日期。完成条件和说明可以直接填写，已有其他信息会保留可见，尚未填写的扩展字段按需从“更多信息”展开。折叠信息不会清空内容，取消整个编辑不会保存修改。

课程内可手动新增笔记、评分项目和日程；评分、日程和下级内容分别翻页。评分权重不等于已取得成绩。资料旁的“建立任务／日程”会保留资料标题、编号和原始位置，页码可由用户补充，不自动猜测资料含义。

点击任务左侧圆圈可明确标为完成。“已完成（数量）”默认折叠，展开后仍能查看和编辑原记录；明确标为未完成会重新回到待办区。仅编辑备注不推翻完成反馈。

任务详情或编辑窗口有“删除任务”。删除使任务退出待办与候选，保留计划、反馈和关联；成功窗口可以“撤销删除”。历史计划中的已删除任务不能继续接受新反馈，恢复后才能更正。课程和项目使用“归档”，有可见子项或未结束关联日程时会要求先处理，不连带删除。

## 今天与每日计划

“今天”显示所选日期的计划、固定安排、候选待办和提醒。日期可切换，不改变电脑时钟。

宽窗口左侧是当前警戒，右侧是当天任务、固定日程和候选待办；窄窗口按上下顺序显示，警戒中有“跳到当天任务”入口。**警戒默认展开并展示具体事项**，不会把已过日期、结果未知的事项判成完成后隐藏。可切换全部、今天到期、已过日期结果待核对、近期提醒、日期待确认；每页五条，使用翻页查看其余事项。分类数量来自完整查询，不是当前五条的数量。周期日程可能按发生范围汇总，详情中保留发生次数；未完整核查时会明确提示。

在顶部输入一件事，点击“添加到 M 月 d 日”：先创建任务，再加入按钮标明日期的安排。已有任务点击“从已有任务选择…”，可以搜索未填写日期的任务。没有当天计划时创建按先后顺序的安排，已有计划则追加；不自动修改任务截止日期，也不猜钟点。已经加入的任务不会重复添加。

若提示“任务已记下，尚未加入某日”，任务已经保存在任务库，只需“重试加入”，无需重新创建。也可以查看已记录任务，或选择“暂不安排，继续记录”。如果加入结果暂时无法确认，应使用“核对上次加入”核对同一次操作。等待时切换日期不会把原请求改成新日期。

“当天候选待办”包含希望在该日或此前处理、当天到期或此前仍未处理的日期相关任务。候选不是已经排入计划；点“加入这天计划”后才成为计划条目。没有日期的任务仍可用上方选择入口查找。

### 手动安排

点“详细安排…”，从任务池勾选任务；跨页、搜索后已勾选的任务会保留，也可直接新建或搜索其他任务。支持常规、低精力、只排先后和休息模式。选中一行后用上移、下移或 Alt+↑／Alt+↓ 调整顺序。完成标准只读；需要补充时选择“编辑源任务”。

时间未知时可留空，只记录顺序和估时。估时不是实际用时，也不能缩减任务完成条件。休息计划不安排工作块；要增加任务，须先明确调整计划方式。

保存会检查明确的硬日程、容量、保护时段、依赖和完成条件。存在未知时段时不能把它当成空闲。已反馈或已经过去的原计划条目必须原样保留；调整其他条目会保存修订版，不抹去历史。实际结果的更正应到“今天”或“复盘”操作。

另一端已修改计划时，旧编辑不能直接覆盖新版本。保留输入，重新读取后核对。

单日编辑草稿按日期和数据空间保留，切换日期、关闭后重开可恢复。草稿不是正式计划，点击“保存计划”才生效；其他窗口已改动草稿时不会静默覆盖。计划版本或数据空间发生变化时，会阻止旧草稿覆盖新记录。放弃草稿只删除未保存的编辑，不清除原计划或反馈。

### 让 Codex 安排

开启助手入口后可从“今天”的助手按钮请求建议或调整。Codex 读取当前任务、固定安排和规则，返回可核对候选。可用时间不明确时先按先后安排，不猜钟点。

候选中的“保存到某日的每日计划”才是保存入口。只看到回答或“候选已接收”，不代表业务计划已经改变。

这个入口绑定打开时的日期。讨论中提到另一日期，不会把原事项自动改成另一日；要安排其他日期，请返回“今天”选择对应日期再打开。

指定一段时间的安排可在普通、未绑定软件事项的 Codex 项目对话中一次提出，由模型逐日读取并保存。当前没有专门的多日排程窗口；逐日保存不是整段期间的单次原子提交，失败时需区分哪些日期已经保存。前一天计划完成的前置任务，也不能当作已经实际完成。

## 复盘、出勤与每周回顾

“今天”中的完成按钮会立即保存结果，操作处显示正在保存、已保存或需要核对的状态。“复盘 → 每日复盘”中的选择先暂存，点“保存所选 N 项”才写入，N 是本次选择的数量。未选择的项目保持原状，不自动算成未完成；复盘图表显示已经保存的结果，不提前计入未提交的选择。

“记录实际情况”可选择没有进入原计划的已有事项，填写明确的结果和可选用时；“查看已保存实际记录”按当天分页回读，保留每次更正及原话。这个列表与原计划图表分开，不把计划外工作加入原计划完成率。“写小结 / 查看已保存小结”保存独立文字记录，不自动推断完成、出勤或掌握程度。

同一窗口内切换日期会保留各日未提交的选择；关闭窗口会提示是否放弃。已经保存的反馈不会因撤回草稿而被清除。反复读取或确认相同结果不会重复累计。

固定课程会按实际发生日期出现在今天和复盘，即使当天没有另建计划。课程使用“已参加”“缺课需补”“未参加”；尚未开始的未来课程不能提前记成实际出勤。只有明确“缺课需补”才建立或关联补课任务。补课完成不改变原来的缺课记录。跨午夜课程按开始日期复盘一次。

每周回顾默认用等高柱形图表示各日事项比例，并分别标明课程出勤、任务完成等类别。缺计划、空计划和未反馈有不同含义；不把缺计划算成失败，也不把比例解释成工作量、掌握程度或实际工时。点击日期可回到当天复盘。可改成每日横条或每日圆环卡片。

## 搜索与自定义图表（Beta 源码）

主窗口顶部可直接输入任务、项目或课程名称，按 Enter 查看结果；Ctrl+K 聚焦搜索框。结果可以翻页，单击选中后点击“打开选中项”或按 Enter，也可以双击打开。当前不搜索资料全文、日程和评分项；这些内容从对应项目或课程页面查找。

在统计面板点击“图表样式…”，会直接定位到该位置的选择；也可从“设置 → 显示”统一调整。五个位置分别保存：总览的今日计划、任务概况，以及复盘的当日反馈、本周汇总可选横条或圆环；每周每天的情况可选比例柱图、横条或每日圆环卡片。选择时展示明确标注的虚构预览，点击固定在底部的“保存显示与图表”后应用。

样式保存在当前数据空间，重新打开仍保留。改样式不改变计划、反馈、完成标准或统计口径；无计划、空计划、未反馈保持不同含义。总览“本周固定日程”仅展示固定日程，不代表全部任务安排。

横向进度、圆环、每日柱图和每日圆环卡片使用轻微渐变，第一次显示有效数据时从空轨道填充到实际位置。课程与项目的横条保持原长度，仅加粗到 12 像素；总览此类横条最大宽度仍为 280 像素。动画只改变绘制，数字、分母和实际结果始终显示最终数据；周期刷新和切换强调色不会反复从零播放。关闭系统动画或启用减弱动画后直接显示最终进度。补课数量进度、项目任务进展和设置中的虚构图表预览也采用相同规则。

## 保存状态与关闭编辑

快速记录、加入当天和完成任务都在操作附近反馈结果。看到“已保存／已记下／已加入”才表示对应步骤收到确认；“正在保存”期间不必重复点击。如果连接中断导致结果未知，请使用当前显示的“核对上次…”按钮，沿用原操作核对，避免重复任务或重复反馈。

普通新建和编辑窗口有修改时，右上角关闭、Esc 或取消都会提示保存、放弃本次修改或继续编辑。只是打开查看而没有更改时可以直接关闭。保存尚在执行或结果未知时，先等待结果或核对原保存；关闭窗口不等于撤销已经送出的操作。

设置窗口关闭时会列出有未保存修改的分区，选择“返回保存”“放弃未保存修改”或“继续编辑”。返回后仍使用各分区自己的保存入口，不通过关闭窗口自动批准助手授权。任务页和今天页尚未提交的输入、批量与拆分窗口的未保存清单，以及计划编辑草稿都有各自的关闭保护；批量和拆分内容不提供跨重启草稿恢复。

## 补课与补欠

课程页的“补课与补欠 → 登记补课 / 补欠”用于登记已经明确落下的范围。填写完成条件、单位、已知总量和累计量，例如总量8讲、已补3讲；未知数量可以留空。

可复用本课程已有任务，保留原身份及记录。未参加、过期或没有反馈本身不等于已经确认欠课，不能自动批量登记。

“更新进度”保存累计已补量，并单独选择是否完成全部条件。数量达到总量不会自动认定掌握、提交、到课或整项完成。降低或清除旧数量、撤回已完成状态，需要明确更正原因；原反馈保留。改变已有范围或计量单位也受到保护，不能把旧进度悄悄挪给另一范围。

“加入某天计划”沿用普通任务流程；登记补欠本身不自动排入每天复盘。

## 每周课表、教学周与临时例外

“今天 → 每周课表 → 导入课表”可选择图片或 PDF，填写名称与适用范围，再让 Codex 整理。核对候选后保存。Excel 课表可另存 PDF 或截图；复杂班别、模糊格子或冲突保持待确认。

也可在表名旁“⋯”管理已有课表或手动添加时段。点击课程格子可编辑系列及单次例外：

- 修改系列星期、时间或教学周会影响该系列后续适用安排。
- “临时例外：单次停课或改时间”仅作用于指定的一次日期。
- 单次例外日期须与该系列原星期一致；当前不能直接把单次课程挪到另一个星期。此类改期需另行核对原次停课与新的单次日程，不能为一周临时变化误改整个系列。

“设置 → 课表”维护时区、教学周编号和明确的 Recess 周。默认可按教学周跳过已登记假期；没有具体假期日期时不会自动猜校历。修改默认设置不直接改写已有课表；选择具体课表后保存才会更新它的规则。

周视图目前没有独立的 Recess 周或教学周标签。空白周既可能是已登记休息周，也可能没有课程，应结合所选课表设置核对。

固定课表、日计划和准备规则使用同一套实际日程。课表本身不自动建立任务、每日计划、出勤或补课反馈。已有准备任务不会因课表改期被覆盖，必要时提示重新核对绑定。

## 准备待办、习惯和提醒

左下角“日常习惯”或“今天 → 日常习惯”打开独立窗口，可查看三类设置：

1. **复盘提醒**：每天/每周提醒时间。提醒出现在软件中；“知道了”只收起提醒，不代填结果。
2. **课前与截止前准备**：围绕日程或截止节点，填写准备内容、完成条件、提前天数和可选估时。
3. **我希望怎样安排一天**：安排习惯、计划时长上限、不排任务的时段和日期提醒。

玻璃界面在宽窗口将前两组并排显示，窗口变窄或字号增大时自动改为单列。短按钮靠近对应内容，右侧箭头表示可以展开；下拉选择和折叠区域打开、收起时，箭头随状态转动。

准备任务先进入指定日期的候选待办，加入日计划后才进入逐项复盘。每次日程独立生成；重复检查不会反复生成同一发生次。节点改期、规则修改或停用，保留已有任务和反馈。新规则从当前业务日开始，后台恢复时按已保存进度有限追补，更早缺口需明确核对。

在“你想设置什么？”中选择一项，下方会显示用途和例子，再点“填写这项设置”：

| 选项 | 什么情况下使用 |
| --- | --- |
| 日常安排习惯 | 用文字说明平时希望怎样安排，例如“先做重要的事”。供自己和可选助手参考，不表示每句话都有程序强制检查 |
| 每天最多安排多久 | 设置日计划时长上限，例如 180 分钟。保存时检查已加入计划的已知用时合计；未加入计划的课表不会自动扣除，未知用时仍待核对 |
| 不安排任务的时段 | 留出睡眠、吃饭等时间，例如 23:00–07:00。保存带具体钟点的计划时检查冲突；只排先后的计划仍需核对具体时间 |
| 日程与截止日期提醒 | 提前几天在今天/总览显示临近日程或截止日期，不是定时闹钟。天数和月数同时填写时取更早的提醒日期，不相加 |
| 这段时间的特别安排 | 写下近期的特殊要求，例如“这周少排任务”。填写结束日期后，在该日期之后不再采用；留空不会自动到期，原记录仍保留 |

时长上限未知时先保持停用，填入明确分钟数后再启用。日期可以限制设置的适用范围；选项中的例子仅供参考，不会自动填入或保存。已有规则可“查看原文 / 修改”。

容量和保护时段在计划保存时校验；估时或钟点未知时仍要保留未确认状态。提前警戒只显示风险，不自动创建准备待办。

后台需要本机业务服务运行。关闭管理窗口不等于关闭服务；电脑睡眠或关机期间不会执行。不包含 Windows 登录自动启动或向外部聊天自动推送的承诺。

## 保存资料与整理笔记

打开课程或项目，在“资料与通知”选择“添加资料或通知”，也可拖入文件。支持托管文件、粘贴文字、明确粘贴截图和保存公开网页快照。

保存前选择归属内的具体文件夹，也可输入相对子目录，例如 `课件/Week 3`。需要直接放在课程或项目根目录时，明确选择“归属文件夹根目录”。软件不会只凭文件名猜测课件、习题或备考分类。保存完成后展示实际归档位置；批量选择的文件使用同一目录，不同分类请分批保存。

已经保存但位置不合适的资料，使用“移动原件…”重新选择目录。这会保留资料编号、内容、提取记录和关联，并同步更新索引；不要自行移动“原文件”中的文件来代替此操作。若新位置存在不同内容的同名文件，会拒绝覆盖。旧位置仍被其他资料引用或已被外部修改时会保留并说明；清理暂时失败可以按原请求重试。

普通 Codex 会话可先查询 `library_destinations`，导入时传 `library_subdir`；已有分类却未指定位置会返回需要选择目录。已有资料更换目录使用 `refile_source`，回读实际位置后才能报告归档完成。受管讨论的直接写入限制继续适用，可在软件窗口完成移动。

默认保存软件管理的副本。相同内容按指纹复用；同名但不同内容另存版本。原文件以后移动或删除，不影响已保存的版本。旧版仅保存路径的引用需要先“保存到软件”，丢失的原件不能凭空恢复。

资料“已保存”与“已完整读取”不同。可以查看提取正文、定位、读取覆盖和警告。PDF、扫描页、常用 Office 文档、文本、邮件正文和图片按支持能力读取；嵌入对象、未处理附件或不支持格式会保留缺口。网页只取公开静态内容，不登录课程平台、不执行网页脚本；需要登录的页面可粘贴正文或截图。

长课件和多页课表采用分批读取与检查点接续，**不再受整份最多8页的旧流程限制**。每批仍有资源和传输预算；大资料可能需要多阶段处理。未读页和解析失败部分不能被当作已读完，也不保证任意文件都能完整解析。

“整理课程信息”从资料中提出课程说明、评分规则、节点和日程候选；“整理课件笔记”使用内置笔记流程，保留来源、概念、例题和未读部分。确认候选后保存。笔记或评分要求本身不自动变成任务，也不等于已经获得成绩或完成学习。

## 两种 Codex 对话

### 软件关联的事项讨论

从每日计划、复盘、课程或其他对象打开的讨论绑定该范围和原业务日期。可在同一个 Codex 会话中继续，候选仍回到原软件事项。标题只是展示，实际归属由保存的关联决定。

有待采用候选时，发送新消息会使旧候选失效；这是为了让新请求使用最新事实。要保留原候选，先核对采用，或明确在下一轮重新提出。新消息不会自动把已保存业务变更撤销。

长任务会分批读取并在原事项、原任务上接续。关闭讨论窗口只停止该窗口的显示和等待，不等于取消已交给桌面的任务。

### 普通项目对话

首次连接后，可从 Codex 的“Codex事务助手”项目进入普通、未绑定软件事项的对话，粘贴通知、邮件或说明希望记录的事情。

普通对话按用户明确要求，可通过 MCP 直接保存已授权的业务变更；只讨论或分析时不保存推测。它与软件共享业务数据，不共享或自动合并全部聊天全文。不能把失效的受管会话当成普通对话绕过确认。

## 中断、取消与恢复

遇到问题先看实时连接状态和本轮处理说明，不必先反复重启两端。

| 情况 | 含义与处理 |
| --- | --- |
| 桌面未连接 | 检查 Codex 是否正常打开和登录，使用“连接 Codex”；已有消息不自动重发。 |
| 正在读取或接续 | 可能仍在分批处理资料或压缩上下文；阶段文字不等于业务已保存。 |
| 超时或发送结果未知 | 保留原任务，先核对原回合和回执，不能直接另发一遍。 |
| 用户明确停止 | 只对已核实的本轮请求尝试停止；远端身份未知时不能保证远端已取消。 |
| “从已保存进度继续”可用 | 沿原操作恢复，不新建同名任务；仍需原身份可核对、没有另一活动任务且数据空间未变。 |
| “恢复原会话关联” | 用于已存在原会话的关联核对；不是普通连接按钮，也不是任意选择一个同名会话。 |

并非所有失败或取消都可恢复。缺少可靠身份、检查点失效、相关资料已变或原回合仍未确认结束时，应按提示核对。取消后的迟到结果不会自动采用；显式恢复会创建新的处理代次，旧回调不能覆盖新进度。

## 文件夹、备份与恢复

课程或项目的“打开文件夹”可查看软件管理的可浏览原件；设置的数据页提供“打开原文件目录”。原件副本默认只读。另存或编辑后，需通过“添加资料或通知”重新导入才成为新的业务资料版本。

“设置 → 数据与高级 → 创建并核验备份”备份业务数据库和已登记的托管版本。仅存外部路径的引用不等于备份了外部文件；没有导入软件的额外文件也不在托管备份范围内。

“恢复备份到新目录”保留当前空间，写入新的空目录。恢复后的数据身份变化，旧候选失效，定时和固定准备配置暂停，需核对后重新启用。重新打开恢复目录并检查 Codex 连接，不能把旧空间的会话关联直接当成新空间已经连接。

## 外观与其他边界

“设置 → 显示”按外观、文字和图表分组。明暗模式可选浅色或深色；强调色可选默认配色、珊瑚、海蓝、鸢尾紫、玫瑰或青碧，两者可以自由搭配。色块下方先显示局部预览，点击“保存显示与图表”后应用到已打开的窗口，重开后仍保留。提醒文字、复盘选中按钮和图表跟随强调色；图表用同色系深浅区分结果，未反馈保留中性色，原始结果名称与计数保持不变。错误和删除操作仍使用独立提示色。Beta 已统一使用当前界面，旧版 UI 和切换入口已退役。

玻璃界面切换设置标签或每日/每周复盘时，选中标签和页面内容会平滑渐变，原有未保存输入和滚动位置保留。关闭系统动画或启用减弱动画时直接切换。

字体、字号和各位置图表样式也在本页维护，短按钮在窄窗口自动换行，保存操作固定在底部。缺少原字体时使用替代字体，保留原保存选择。项目目录可收起或展开。课表、Codex 协助、数据与高级页同样按用途分组；颜色设置不会启用助手或改动业务记录。

长标题与说明随实际宽度换行，字号增大时内容区相应增高。设置和版本页中的长目录可完整换行查看，并选中复制原始路径；版本说明较长时滚动正文，底部操作仍保持可见。

高级文档成果生成、成果版本和采纳接口主要供 MCP 或开发接入，当前没有覆盖全部成果流程的独立 GUI。登录平台抓取、完整邮件账号同步、任意格式无损解析和自动跨日最优排程也不属于本版承诺。

v1.0.0 基于已冻结功能发布，用户已完成日常使用体验验收。该结果不代表所有场景清单、全部硬件组合和长期稳定性都逐项验证。
