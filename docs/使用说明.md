## 首次连接 Codex（0.11.2）

设置 → Codex 协助 → 启用 → 保存并连接 Codex 项目。软件会准备并打开固定的“Codex事务助手”项目，自动接通当前数据空间的 MCP，不需要手动添加目录或复制接口配置。首次打开为空白输入框，不会自动发送消息。

临时群消息、邮件、通知、截图及文件都可在此项目中新建任务交给 Codex 处理；对话保存的任务、计划与反馈会反映到软件界面。每次新对话读取最新业务记录，无需依赖旧聊天记忆。软件升级或迁移后重新保存此设置即可检查并修复连接。

# 个人事务管理 0.11.2 使用说明

## 第一次使用与快捷方式

日常直接双击桌面的“个人事务管理”，也可以从开始菜单搜索同名程序。这两个快捷方式绑定创建时选择的数据空间。程序、窗口与快捷方式共用蓝色计划卡片图标。

项目根目录的“启动个人事务管理.vbs”仍然可用。若移动了软件文件夹、换电脑或更换数据空间，打开发布包中的“创建快捷方式.vbs”，选择要使用的数据目录，即可重新创建入口。此操作只建立启动链接，不迁移业务数据。

在 Windows 的快捷方式菜单中，也可选择固定到开始菜单或任务栏，具体菜单随系统版本略有不同。

日常入口为总览、今天、项目与课程、复盘。首次启动使用空数据空间；已有资料需由用户明确导入。

## 建立课程、项目和任务

每类事项有自己的创建窗口。课程填写课程名称和可选代码，项目填写目标与验收条件，活动填写活动信息，任务填写归属和完成标准。

课程、项目、活动默认独立建立。“分类”是可选的长期整理方式，例如学习、健康、职业；它是原来“领域”的新名称，不是另一门课程。需要时再勾选分类。任务可以属于课程或项目；在项目中建立子项目时，会明确显示父项目。

课程的“学期与更多信息”中可以补充第一教学周周一和学期结束日期。没有填就保持未知；软件不会猜测第几周对应的日期。

## 上传整周课表，建立每周框架

在“今天”点“每周课表” → “导入课表”。只需三项：选择课表图片/PDF（按钮右侧箭头可以粘贴截图）、给课表起名、选择适用范围。点“整理课表”会保存软件副本并进入 Codex 讨论，识别完成后核对候选并确认。原文件移动或删除不影响已保存副本。Excel课表先导出PDF或截图。

起始范围选择第一教学周；选择该周中任一天会显示对应周一，结束日包含在范围内。周视图按实际日期显示已确认课程，日常只保留日期导航和导入；表名旁“⋯”中可以管理已有课表、手动添加时段或查看停用的时段。点击课程格子编辑该系列及单次停课/调时。不连接 Codex 也可手动建立框架。

时区与假期在“设置 → 课表”。新课表默认 Recess week 不计入教学周；请按校历加入明确的假期周。比如第7教学周后休息一周，随后继续第8教学周，单双周课程据此安排。假期本身不安排课表课程。默认设置可保存多个学期的日期，导入时只取所选范围内的日期。

已有课表不因默认设置变化就自动改周号。在设置上方选择具体课表，再保存，会统一更新它的实际固定时段。旧版按日历周保存的课表会保留原含义，确认改成教学周后才跳过假期。已经生成的准备任务及历史记录保留，必要时提示重新核对绑定。

相同名称和适用范围再次上传会复用已有课表，保留已确认的设置。新资料整理时核对原时段，不重复创建；未列出的旧时段也不会直接删除。所有课时与每日计划共用日程数据，生成每日计划时避开固定课程。课表不会自动创建任务、补课事项、每日计划或完成反馈。

课表PDF同时读取文字和布局，每次最多8张图片/页；超过需要拆分。复杂班别、模糊格子和时间冲突保留待确认，不自动选班、猜日期或挪课。

## 删除测试或不再需要的任务

点开任务，在详情下方点“删除任务”；编辑任务窗口也提供这个入口。确认后任务会从课程任务列表和待办候选中移除，成功页可立即“撤销删除”。

删除保留原计划、反馈与关联证据。历史计划中的条目显示“已删除”，不会继续要求复盘或接受新反馈；恢复后可以继续操作。有未处理子项时会提示先处理，不会连带删除。

“今天”右上方的“手动安排”使用明显边框和加粗文字，可直接自己安排；“让 Codex 安排”是自然语言协助入口。

## 字体、深色模式与目录

设置 → 显示，可以选择本机字体、字号和浅色/深色主题。深色使用中性灰黑背景、白色文字和蓝色强调色。保存后已打开窗口跟随更新；浅色默认保持原来风格。换电脑缺少原字体时会明确使用替代字体，不改写原保存选择。

项目与课程的“项目目录”右上可收起，收起后保留“展开目录”按钮；当前选中课程和保存偏好保留。

## 课程记录的编辑与含义

实际任务是要执行的具体工作，不表示已经排入某天。“交付与重要日期”记录明确交付、截止日或阶段检查点。一般课程参与要求应保存在课程说明或笔记，不能凭此自动建立周期任务。

此前已保存的记录保留来源。未明确日期的节点显示编辑说明与日期入口，不再处处显示准备规则；一次性节点是“截止前准备”，重复日程才是“每次提前准备”。日程、评分、任务、笔记和节点都可从对应条目编辑；后台与外部Codex的update接口同样可用。只读或归档对象的边界仍受业务校验。

## 补课与补欠

每门课程有“补课与补欠”。点“登记补课 / 补欠”，写需要补的范围、完成条件、计量单位及已知数量。例如总量8节课、累计已补3节；未知可以留空。也可复用本课程已有任务，保留原编号及记录，不额外创建第二个任务。

“记录补欠进度”记录累计已补量，并可单独明确已完成或未完成全部条件。数字达到8/8不会自动声明掌握、提交或到课。降低或清除旧数量需选择更正并说明原因，历史反馈保留。“加入某天计划”沿用普通任务流程，排入日计划后进入当日复盘。未到课、日期过期或缺少反馈不会自动被算成欠课。

也可以在课程讨论里说：“我落下了8节，目前补了3节，请登记补课，完成条件是补完课程并完成对应练习。”Codex提出候选后核对保存。

## 用会话整理课件笔记

先在课程添加课件，再点“整理课件笔记”，或在课程讨论里直接说“这是这门课的课件，整理笔记”。软件会使用打包的course-notes技能，依据实际读取的内容整理概念、公式、适用条件、例题和闭卷自测，标明来源及未读部分。笔记正文在讨论中查看，需要保存时核对候选。

课程首页只保留简短的笔记标题与摘要，可以打开阅读、继续在Codex中整理或手动编辑。笔记整理不会自动建立任务、里程碑或完成反馈。外部Codex若另行安装同名技能，可使用 `$course-notes`；新会话能发现已安装技能。软件内会话不依赖外部会话读取该技能。

## 把资料和新信息交给课程

打开课程或项目，在“资料与通知”中点“添加资料或通知”，也可以拖入文件。

- 文件：课件、PDF、Word、PowerPoint、文本、邮件文件等。
- 文字：直接粘贴临时通知或邮件正文，可以补一个便于识别的名称。
- 截图：复制截图后，在添加窗口明确选择粘贴截图。
- 网页：粘贴公开网页链接，保存本次取得的静态正文快照。

**默认保存软件管理的副本。** 原件之后移动、改名或删除，已保存的版本仍可用。相同文件内容按指纹复用，不反复存一份相同大文件。原件更新后需要重新添加，形成新的内容版本；不会悄悄覆盖已经采用的依据。

旧版只保存路径的文件会明确显示为引用。选择“保存到软件”后才能获得副本保护；已经丢失的旧原件不能凭空恢复。

资料会显示实际读取状态。可预览提取正文、来源、读取页数和警告，也可以打开保存版本。读取失败或格式不支持时仍保存原件，不能把“已保存”理解成“Codex已读懂”。

目前支持 PDF文字及扫描页图片、DOCX/PPTX文字与备注、普通文本、.eml邮件正文和图片。Office内嵌图表、未读取的邮件附件会明确提示；重要图表可另附截图。.msg、老式Office或其他未支持格式仍可保存，但需另存PDF/.eml或粘贴正文才能自动整理。

网页不读取登录账号、不运行脚本。需要登录的课程平台、内网页面或动态内容，使用粘贴正文或截图。网页快照默认以安全正文预览，不运行原网页脚本。

## 一键整理课程信息

先添加课程介绍、评分说明、日程或通知，再点“整理课程信息”。配置正常时会直接开始读取并讨论，不用逐项手建。

Codex 会提出原文已有的评分组成与权重、截止节点、固定日程、每周安排等。课程页会显示保存后的评分规则和安排。评分权重不等于实际成绩；资料没有写明的日期、时间、学期锚点和规则会留待确认。

先核对回复下面的候选与来源，再点确认保存。同一课程的同名同值内容会复用；同名但内容不同需要明确更新，不能悄悄新增重复定义。一次候选最多30项，大范围课程信息需要分批核对。

## 与 Codex 讨论

界面是自动保存的连续讨论：中间为消息，底部为输入框、附件和发送。Enter发送，Shift+Enter换行；处理中可停止。

同一天的计划调整自动回到同一段计划讨论，同一门课程也自动回到自己的讨论。无需复制问题到外部对话，也不需要按“继续上次讨论”。新消息会重新读取当前业务事实；旧候选不会覆盖新事实，继续讨论后旧候选不能再被采用。

附件可以在输入框上方移除，移除只改变后续讨论参考范围，不删除资料。每轮最多12份资料、8张图片；超过正文或解析预算时会明确提示分批，不会默默截断后宣称已读全。

尚未启用时，讨论窗口只引导“连接 Codex”。在设置中启用本机Codex，并确保已登录。界面不会复制或导出账号凭据。普通手动记录与复盘不依赖模型。

外部Codex仍可以通过设置中的MCP配置操作同一数据空间，新对话先读取当前状态。软件内讨论和外部Codex聊天是两个界面，共享的是业务记录，软件不会自动向某个已有外部聊天发送消息。

## 任务、截止节点与固定准备事项

课程页将“实际任务”“截止节点与成果”“知识点与笔记”分开。评分规则解释课程如何计分，笔记保存要求；它们本身不会自动变成今天必须执行的任务。

今天页的“当天候选待办”只显示已指定日期、当天到期或此前仍未处理的任务。未指定日期的其他任务仍在项目或课程中。点击“加入这天计划”，或者打开任务详情选择日期后加入，才会进入那天的逐项复盘。新建的计划默认不猜具体时间；原有计划会保留。重复点击不会重复加入，休整日需要先明确调整计划。

在日程或截止节点旁点“固定准备事项”，填写准备内容、完成条件、提前天数及可选估时。例如每周实验课前两天出现“完成课前练习”。也可以在与 Codex 讨论中直接说明要求，核对其规则候选后保存。新建日程与绑定规则分两步：先保存日程，再继续让 Codex 设置准备规则。

规则跟随节点的重复频率，每次生成独立任务，先成为相应日期的候选待办，不自动排计划、不自动打勾。节点缺少明确日期时不会生成；改期、停用或修改规则会保留已有任务并提示核对，不覆盖执行反馈。确认重新绑定只影响后续生成。服务运行时生成当前业务日的准备事项；重新启动时会按上次处理进度补齐漏过的日期，最多追补31天，更早的缺口会提示核对。新规则从当前日开始，不自动建立过去的任务。电脑关机期间不运行；更早日期可通过 Codex 明确分批补齐（每次最多31天）。

## 模型选择与资料依据

设置 → Codex 的模型改为下拉选择，列表来自本机 Codex，可手动刷新。“跟随本机 Codex 设置”保留本机配置；读取失败或原模型不在列表中时保留原选择，不偷偷更换。列表刷新不发起AI对话。

软件内讨论使用软件提供的当前记录、所选附件及该范围的讨论历史；后台配置禁用个人记忆读取，且不开放文件、网络和外部工具。每次资料整理仍需核对来源页码、读取覆盖和未知项。来源不全时，旧聊天和模型常识不能补成已确认的课程事实。

## 今天、复盘与图表

今天显示每日计划、固定安排和提醒。可以让Codex生成或调整计划，也可以手动选择任务安排。

每日复盘按计划逐项选择完成或未完成，未选保持未反馈。反复读取和相同结果保存不新增重复反馈；到课、提交、掌握和实际用时不由完成状态推断。没有明确计划时，可在连续讨论中按实际情况复盘。

每周回顾默认使用等高纵向柱形图：每天都是100%高度，内部颜色显示完成、未完成、未反馈和已有细分反馈。缺计划、空计划单独显示，不算0%失败；柱下保留任务项数，比例不是工作量或掌握程度。

设置中的“显示”可以改用横向进度条。日期选择器可展开完整月份选择日期。

## 提醒、备份与恢复

设置首页可启用每日复盘时间、每周回顾的星期与时间。提醒出现在今天页；“知道了”只收起提醒，不代表完成。电脑关机期间不运行，尚未安装系统登录自动启动，也不向外部Codex聊天自动推送。

备份包含业务数据库、已托管的原件和可读取的衍生内容；旧路径引用仍只备份路径。恢复到新目录，保留当前数据。恢复后旧候选失效，原定时任务和固定准备规则暂停，软件内讨论保留但会重新建立模型连接。

遇到另一端改动造成的冲突，请保留当前输入并重新核对。写入连接中断时先查原回执，避免手动创建重复事项。


## 0.8 每日计划与已完成记录

在“今天”点击“让Codex安排”，或在日常讨论输入“生成今天的计划”。软件读取已有任务和固定安排，不要求重新填写每门课的情况。时间或可用容量不确定时，先给按先后顺序推进的计划；未知事项保留，不猜测钟点。回复中的计划卡片列出事项名称，点击“保存到 YYYY-MM-DD 的每日计划”后，才会显示在当天并支持逐项复盘。已有明确反馈和已经过去的计划块会保留；其他入口有新修改时需重新读取候选。

项目和课程中的“实际任务”先显示未完成项。底部“已完成（数量）”默认收起，展开后可分页看全、查看和编辑原记录。把事项重新打开会回到待办区；仅编辑备注不会推翻已有完成反馈。


## 0.9 固定 Codex 项目与原文件目录

内部协助固定使用当前数据空间下的“Codex事务助手”目录作为 Codex 项目。新讨论在这个项目下建立会话，同一段讨论继续原会话；当天计划、其他日期和各门课程保持独立上下文。旧临时目录的会话第一次继续时，会根据软件保存的讨论记录和最新业务事实，在固定项目下建立会话。软件移动或恢复后，会重新连接新位置，业务记忆仍以数据库为准。

课程或项目首页点击“打开文件夹”可用资源管理器查看课件。设置的数据页提供“打开原文件目录”。已迁入的原件存放在数据空间的“原文件/Y2S1”下，保留原目录和文件名；新导入的课件、通知、邮件和截图自动保存在所属课程或项目的目录。同名但不同内容的文件分开保存，不覆盖旧版本。

数据库保存事项、记忆、反馈和检索索引；这些信息不依赖课件文件是否还在原来的外部路径。原件目录是独立的可读副本，不与内部不可变内容存储共用可写文件。为保留导入时的版本，副本默认只读；在原文件目录另存或编辑的内容，需要通过“添加资料或通知”重新保存到软件后才成为新资料，不会静默更新既有记忆。

原件目录中的文件被移动或删除后，可从所属对象重新打开或准备文件夹，利用内部副本恢复；软件不会覆盖已编辑的文件。备份保留数据库和不可变原件，恢复后首次打开文件夹会按保存的相对路径重新还原，无需重新访问旧的 Y2S1 目录。仅在目录中新增、未导入软件的文件不在软件备份范围内。直接复制整个数据空间则保留该目录中的全部文件。


## 0.10 日常习惯与自动安排

“今天”页上方的“日常习惯”显示每日复盘、自动准备和计划偏好的当前状态。点击后打开设置的“日常习惯”页；这里的查看和预览不会替你启用任何规则，也不创建新待办。

复盘提醒：查看是否开启以及下一次触发时间；展开“调整提醒时间”修改每天/每周的设置。提醒只在软件中提示你复盘，不会代填完成结果，也不自动生成日计划。电脑关机或睡眠期间不会执行。

自动准备待办：现有规则显示提前天数，以及未来7天会生成或已经生成的待办日期。选择近期日程或截止节点，可以“与Codex设置”或“手动设置”。已有明确的提前警戒天数会作为表单建议，保存配置后才启用。固定课表提供每周时间框架，不会仅因存在课程就创建准备任务；取消、Recess周和教学周遵循当前课表，课表与实际安排不符应先核对。

安排习惯与提前警戒：逐条显示“安排时参考”“已启用”“已停用”“尚未到生效日期”“已到期”或“范围待核对”。警戒只显示风险；文字习惯交给Codex在你请求安排时参考，并不代表每句话都有程序硬校验；容量和保护时段则由计划保存校验。可修改选中规则、添加文字习惯，或与Codex讨论当前规则，候选仍需核对后保存。

停用、过期或已结束的习惯不再进入新的计划上下文；历史计划和反馈保留。准备规则的调整也不会覆盖已生成的任务。自动待办先进入当天待办，排入日计划后再逐项复盘。缺课和漏报不会自动推断成新的补欠任务或完成结果。

当前周期待办围绕已登记日程或截止节点生成，独立“每周做一件事”尚无单独的简化入口。界面中的“范围待核对”表示筛选条件可能未覆盖标题所指的全部对象，应核对或通过对话拆分规则；程序不会仅按标题扩大适用范围。


## 0.11 总览、任务完成与清晰课次

启动默认进入“总览”。大号显示当天日期、星期、按当前课表计算的教学周，以及本周固定安排、今日计划完成量、当前警戒和课程/项目任务进度。Recess week不冒充教学周；没有适用课表时明确显示未设置。周卡可进入所选日期，长字体自动换行排布。

每项课程任务独立显示课程代码。今天计划可直接点“完成”或“未完成”，与复盘使用同一份完成反馈；课程任务列表左侧圆圈可直接完成，在详情里可重新打开。只记录明确选择的完成维度，不据此推断出勤、观看、掌握或提交。原任务的完成条件仍保留。

当前和未来警戒使用醒目色块；已过日期或当天已结束的明确日程默认折叠。过去的结果未知仍保留，不视为已完成。日期未知的事项保留在当前待核对中。当日候选按课程/项目分组，组内按安排/截止日期从旧到新排列，读取有分页。

手动安排直接载入所选日计划、当天候选和真正落在当天的固定安排；无日期事项单独收起，不混入固定时段。候选没有收录的其他任务可搜索添加。保存已有计划形成修订，保留已反馈或已经执行的块；并发修改会明确提示，不覆盖其他端的新记录。界面不展示内部ID。

补课与补欠就是同一门课程下的实际任务。已有事项可直接登记累计已补数量（未知时不按零算），或确认完成；普通登记说明可留空。数量满额仍需要明确完成确认。查看、更正旧记录放在展开区。Lecture、Tutorial、Quiz、PQ、OQ保留资料明确的编号；日期和教学周不自动转成课号，缺少编号会显示待确认。

日常习惯默认只显示“什么时候提醒我复盘”“课前与截止前准备”“我希望怎样安排一天”三个区域。设置课前准备、调整安排偏好可用自然语言说明，原始规则和手动配置按需展开。查看界面不会自动启用准备规则或改变已有偏好。


## 连续讨论与超时（0.11.3）

生成计划后，可以直接补充某项已完成、尚未完成或进度变化。即使从“调整计划”入口打开，将预填内容换成反馈时，也会按反馈处理；只有明确要求排计划才进入计划专用流程。返回的变更仍需核对保存。

“处理超时”表示设置的等待时间内没有拿到完整结果，不等于项目或数据库连接丢失。新版提示会写明所处阶段，本次未生成可保存候选。可稍后重试；确需更长等待时调整设置中的“单次等待上限”。刷新连接配置不能延长某一轮的等待时间。


## 在 Codex 桌面实时查看（0.12.0）

在“设置 → Codex 协助”把处理方式选为“在 Codex 桌面同步显示”，保存一次。首次启用时，先保存并退出 Codex，再点“启动 Codex 连接模式”。以后在管理软件里按一次发送，任务会交给同一个 Codex 服务；可在 Codex 查看消息、处理过程与回答。后台得出的变更仍在管理软件中核对后保存。

连接模式需要与当前 Codex 版本配合。它不会自动关闭已有 Codex 任务；普通模式的 Codex 已打开时，会提示重启。Codex 完全关闭后，在管理软件发起请求会自动按已保存的连接方式启动。需要直接启动时，也可使用设置中的“启动 Codex 连接模式”。

管理软件讨论窗口会立即显示正在发送的消息，再根据实际回执更新状态。等待时显示阶段与耗时，已生成的文字逐步出现；部分回复会标为未完成。发送结果不确定时先核对回执，不会自动把同一条消息发送两遍。失败不会把候选当作已经保存。

刷新配置会复用已有“Codex事务助手”项目。“打开 Codex 事务助手”用于进入普通讨论；具体后台任务旁的“在 Codex 查看”用于查看该次处理。仅在管理软件处理的旧模式中，处理结束后才能打开后台任务，避免两端争用独立连接。


## 0.13：固定课程与连续讨论

今天和每日复盘会自动列出当天固定课程，即使没有另建每日计划也可以逐项记录。课程提供“已参加”“缺课需补”“未参加”；只有明确选择“缺课需补”才会建立或关联补课事项。补课进度沿用课程的补欠入口，完成补课不会改变原来的缺课记录。课次编号未知时显示“课次待确认”，不会按日期猜测编号。休息周、停课和课表未选中的教学周不生成待补记录。跨午夜日程只在开始日期复盘一次。

软件发出的讨论固定关联原 Codex 任务。可以在该任务中继续发送消息，新的上下文与候选会回到软件里的同一事项。候选通过业务接口持久保存，确认后才会修改正式记录。超时或拒绝不会自动另建同名任务；无法确认的发送会保留原记录并提示核对。连接方式或数据空间发生冲突时不会自动改接其他任务。

更新后，如果 Codex 仍使用旧连接程序，请完整退出 Codex，再使用项目目录内“启动Codex连接模式”启动。个人数据不需要重新迁移。

若断连提示创建结果未确认，讨论窗口会显示“恢复原会话关联”。从列表选择对应的原任务即可继续；列表显示标题和创建时间，不必抄写任务编号。关联恢复保留历史，不新建任务。


## 0.14：大范围资料和长讨论

使用入口保持不变。在课程里添加课件、邮件或截图，再用“与 Codex 讨论”说明目标即可。软件先提供资料目录和当前业务索引，Codex 按需要读取。整理长课件或多份附件时会自动分批，讨论窗口显示已处理批次和正在接续的状态，不必把文件拆成多条消息。

仅反馈“某项已完成”时，旧课件作为可查询参考，不会强制重新整理整门课程。要求整理全部资料时，未处理部分不会被当作已读；无法解析的格式或内容会在结果里列为待确认。

自动接续始终沿用原事项和原 Codex 任务。短暂断连会在核实任务身份后尝试接续；仍然失败可点击“从已保存进度继续”。进度和原件会保留。若提示资料或规则已改变，需要在原讨论重新核对相关部分，不要另建同名讨论来规避冲突。

大量候选会显示摘要并提供完整变更查看入口。确认保存会一次校验并采用全部候选，不只保存预览中可见的几项；任何一项不合法都会阻止整批保存。读取、分析完成与正式业务保存仍是不同状态。

更新软件后，请在本轮工作结束并保存草稿后完整退出 Codex，再使用“启动Codex连接模式”启动一次，以加载新读取接口。无需重新迁移数据或建立项目。


## 0.14.1：复盘与界面细节

每日复盘的“已参加”“缺课需补”“未参加”会高亮当前选择；已保存的结果在重新打开后也保持高亮。未保存的选择仍需点击“确认所选结果”，不会因查看或切换日期自动提交。日期两侧箭头可切换前后一天，原日期的未提交选择会保留。

周回顾按课程任务、项目任务、课程出勤和固定安排等实际类别标注结果，不再统一显示“其他”。每根柱下列出该日的具体分类计数；小色块可悬停查看，不以参加课程替代完成学习任务。

总览只独立列出顶层课程与项目；子项目的任务进度汇入所属课程或项目，改回顶层后会重新独立显示。设置页可随字号滚动，输入框不再被下方按钮挤压。新建菜单的箭头会随展开和收起翻转。
