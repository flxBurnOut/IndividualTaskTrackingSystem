# 个人事务管理 v1.1.1 使用说明

本软件在本机保存课程、项目、任务、计划、资料和执行反馈。日常入口是“总览”“今天”“项目与课程”“复盘”。Codex 协助可选；手动记录与复盘不需要模型连接。

## 安装、升级与数据位置

首次使用运行 `PersonalManagement-1.1.1-Setup-x64.exe`。程序默认安装到 `%LOCALAPPDATA%\Programs\PersonalManagement`，数据默认放在 `%LOCALAPPDATA%\PersonalManagement\data`。安装器按当前 Windows 用户安装，并显示本次使用的数据位置。

打开新空目录会建立空数据空间。已有用户在安装器中核对原数据目录，无需把数据复制进程序目录或重新导入。升级优先继承已保存的数据位置；从旧版升级时，也会尝试读取已有软件快捷方式。无法确认或多个入口指向不同空间时，必须选择要继续使用的目录，不会静默猜成默认空空间。便携版用户可安装到独立程序目录并选择原数据位置；旧便携程序文件不会被自动删除。

“选择数据空间”入口或 `PersonalManagement.exe --choose-data` 只改变本次打开的目录。需要长期使用另一目录时，通过“为已有数据创建快捷方式”创建绑定该目录的快捷方式；已登记的安装版会同时记住该位置，供下一次升级延续。选择目录不会合并或重置已有内容。一个安装版的主快捷方式绑定一个空间，其他空间仍保留，可另建快捷方式。

升级操作：

1. 在主窗口打开“版本与更新”，核对软件版本、后台版本和数据位置。保存并关闭其他编辑窗口，等待后台及 Codex 任务结束。
2. 点击“退出并准备更新”。有任务、导入或保存正在执行时会拒绝退出；安全退出后，后台保持暂停，避免 MCP 自动把旧服务重新启动。如果取消升级，重新打开管理软件即可恢复使用。
3. 运行新版安装包，核对程序目录和数据目录。已登记的安装版使用原程序目录替换程序，个人资料保持在原数据目录。若 Codex 仍加载着此目录中的 MCP 程序，安装器会提示占用；请先结束任务并暂时关闭 Codex，再继续安装。安装器不强制关闭程序。此限制针对替换正在使用的程序文件，日常连接仍支持任意启动顺序。
4. 从更新后的快捷方式启动。旧数据库先进行完整性检查和升级前快照，再在一个事务中更新结构；失败则回滚此次结构更新，保留原记录。课程、任务、计划、反馈、设置、材料和会话关联继续使用。启动后可在“版本与更新”重新核验。
5. Codex 接口需要重新加载后才会获得新工具。新版服务会拒绝旧入口继续执行操作；页面分别展示后台版本和最近一次 MCP 请求的版本，不把写好配置或桌面连通当作所有会话均已刷新。

1.0.x 没有“退出并准备更新”入口。首次从这些版本升级时，关闭窗口后仍可能有旧后台进程。应先结束任务并退出旧软件及其后台；若无法正常退出，可在下一次 Windows 登录后、启动两端之前安装。之后的升级可使用新的准备更新入口。

升级快照位于原数据目录的 `upgrade-backups`，只包含数据库及核验记录；资料文件留在原位置，并不是每次复制所有附件。需要完整业务备份时，先使用“设置 → 数据与高级 → 创建并核验备份”。不会自动用旧快照覆盖用户后续新增记录。数据库被较新版本打开后，不支持直接使用旧程序降级；如需恢复，保留当前空间，并将合适的完整备份恢复到独立目录。

普通卸载保留业务数据及升级快照。安装器只管理自己的程序文件，不清空未知目录。本版不自动下载更新，需运行从可信来源取得的新版安装包。

本版本没有代码签名，Windows 可能显示来源或发布者提醒。请核对下载来源及文件信息。

## 关闭窗口、后台状态与退出

关闭主窗口后，后台继续运行，Windows 任务栏右下角的通知区域保留“个人事务管理”图标。如果未直接显示，请打开“显示隐藏的图标”；也可将图标拖到任务栏常显位置。

- 悬停或右键查看后台是否运行，以及执行中、排队、待核对的任务数量。灰色图标与文字提示表示后台未运行或状态暂时无法确认；后台运行不代表 Codex 桌面也已连接。
- 双击图标或选择“打开个人事务管理”重新打开窗口。重复打开快捷方式会转到已有窗口，同一数据空间不重复开窗。
- “版本与更新”打开升级入口；“检查后台状态”立即重新核验。多个数据空间各有图标，菜单显示对应的数据位置。
- “退出软件与后台”检查尚未结束的任务与保存操作。存在未保存的编辑窗口时会提示先保存；不会强行终止任务或丢弃编辑。成功退出后图标消失，后台保持暂停，重新打开软件可恢复使用。

后台通过 Codex 的 MCP 接口单独启动时也会显示图标。托盘意外退出后，运行中的后台会重新建立图标。本功能不提供 Windows 登录自动启动；电脑睡眠或关机期间不会执行任务。

## 第一次连接 Codex

1. 在本机安装当前 Windows Codex，并自行完成登录。
2. 打开“设置 → Codex 协助”，启用协助，选择“在 Codex 桌面同步显示”，按需要选择模型，然后点“保存设置”。
3. 点“连接 Codex”。软件核对专用项目和业务接口，并连接正常启动的 Codex。已有明确拒绝信任或自定义配置冲突时，会提示核对，不覆盖你的选择。
4. 以主窗口、设置页和讨论窗口共用的实时状态为准。“项目已准备”或过去连接成功不等于当前已经连接。

日常可按任意顺序启动管理软件和普通 Codex。任一端关闭后重新打开，软件会重新检查连接；不需要每次切换启动模式，也不应靠反复重启解决普通断连。

Codex 未打开时，自动状态查询不会反复把它拉起。明确点击“连接 Codex”或“连接并发送”时，软件才可通过 Windows 正常入口打开当前 Codex。连接恢复不自动重发旧消息。

“连接并发送”只保留本次点击时的草稿。等待期间修改文字、改变附件、关闭窗口、取消等待或等待超时，都会撤销这次待发送动作。之后需要按当前内容重新明确发送。

也可选择“仅在管理软件中处理”。这是独立处理方式，不保证回答实时出现在当前 Codex 桌面，不是桌面连接失败时的自动替代方案。

## 建立课程、项目和任务

在“＋ 新建”选择类型：

- 课程填写名称、可选代码和说明。未知学期日期留空；没有第一教学周依据时不猜周号。
- 项目填写目标和验收条件。在项目内添加子项目时，界面会显示所属父项目。
- 任务填写具体工作、完成条件、可选估时和日期。任务可属于课程或项目，也可独立存在。
- 分类是可选的长期整理方式，例如学习、健康、职业，不等于一个待完成任务。

打开课程或项目后，可在“实际任务 → ＋ 添加任务”新增。编辑时保留未修改字段；移动已有归属在左侧项目目录中拖放，非法类型、自己或自己的下级不能成为新归属。

点击任务左侧圆圈可明确标为完成。“已完成（数量）”默认折叠，展开后仍能查看和编辑原记录；明确标为未完成会重新回到待办区。仅编辑备注不推翻完成反馈。

任务详情或编辑窗口有“删除任务”。删除使任务退出待办与候选，保留计划、反馈和关联；成功窗口可以“撤销删除”。历史计划中的已删除任务不能继续接受新反馈，恢复后才能更正。课程和项目使用“归档”，有可见子项或未结束关联日程时会要求先处理，不连带删除。

## 今天与每日计划

“今天”显示所选日期的计划、固定安排、候选待办和提醒。日期可切换，不改变电脑时钟。

“当天候选待办”包含已安排到该日、当天到期或此前仍未处理的任务。无日期任务仍在课程或项目中。候选不是已经排入计划；点“加入这天计划”后才成为计划条目。重复加入同一任务不会增加副本。

### 手动安排

点“手动安排”，从候选勾选任务，也可“搜索其他任务”。支持常规、低精力、只排先后和休息模式。

时间未知时可留空，只记录顺序和估时。估时不是实际用时，也不能缩减任务完成条件。休息计划不安排工作块；要增加任务，须先明确调整计划方式。

保存会检查明确的硬日程、容量、保护时段、依赖和完成条件。存在未知时段时不能把它当成空闲。已反馈或已经过去的原计划条目必须原样保留；调整其他条目会保存修订版，不抹去历史。实际结果的更正应到“今天”或“复盘”操作。

另一端已修改计划时，旧编辑不能直接覆盖新版本。保留输入，重新读取后核对。

### 让 Codex 安排

无计划时点“让 Codex 安排”；已有计划时点“调整计划”。Codex 读取当前任务、固定安排和规则，返回可核对候选。可用时间不明确时先按先后安排，不猜钟点。

候选中的“保存到某日的每日计划”才是保存入口。只看到回答或“候选已接收”，不代表业务计划已经改变。

这个入口绑定打开时的日期。讨论中提到另一日期，不会把原事项自动改成另一日；要安排其他日期，请返回“今天”选择对应日期再打开。

指定一段时间的安排可在普通、未绑定软件事项的 Codex 项目对话中一次提出，由模型逐日读取并保存。当前没有专门的多日排程窗口；逐日保存不是整段期间的单次原子提交，失败时需区分哪些日期已经保存。前一天计划完成的前置任务，也不能当作已经实际完成。

## 复盘、出勤与每周回顾

“今天”中的完成按钮会立即保存结果。“复盘 → 每日复盘”中的选择先暂存，点“确认所选结果”才写入。未选择的项目保持原状，不自动算成未完成。

同一窗口内切换日期会保留各日未提交的选择；关闭窗口会提示是否放弃。已经保存的反馈不会因撤回草稿而被清除。反复读取或确认相同结果不会重复累计。

固定课程会按实际发生日期出现在今天和复盘，即使当天没有另建计划。课程使用“已参加”“缺课需补”“未参加”；尚未开始的未来课程不能提前记成实际出勤。只有明确“缺课需补”才建立或关联补课任务。补课完成不改变原来的缺课记录。跨午夜课程按开始日期复盘一次。

每周回顾默认用等高柱形图表示各日事项比例，并分别标明课程出勤、任务完成等类别。缺计划、空计划和未反馈有不同含义；不把缺计划算成失败，也不把比例解释成工作量、掌握程度或实际工时。点击日期可回到当天复盘。显示设置可改成横向条形图。

## 补课与补欠

课程页的“补课与补欠 → 登记补课 / 补欠”用于登记已经明确落下的范围。填写完成条件、单位、已知总量和累计量，例如总量8讲、已补3讲；未知数量可以留空。

可复用本课程已有任务，保留原身份及记录。未参加、过期或没有反馈本身不等于已经确认欠课，不能自动批量登记。

“更新进度”保存累计已补量，并单独选择是否完成全部条件。数量达到总量不会自动认定掌握、提交、到课或整项完成。降低或清除旧数量、撤回已完成状态，需要明确更正原因；原反馈保留。改变已有范围或计量单位也受到保护，不能把旧进度悄悄挪给另一范围。

“加入某天计划”沿用普通任务流程；登记补欠本身不自动排入每天复盘。

## 每周课表、教学周与临时例外

“今天 → 每周课表 → 导入课表”可选择图片或 PDF，填写名称与适用范围，再让 Codex 整理。核对候选后保存。Excel 课表可另存 PDF 或截图；复杂班别、模糊格子或冲突保持待确认。

也可在表名旁“⋯”管理已有课表或手动添加时段。点击课程格子可编辑系列及单次例外：

- 修改系列星期、时间或教学周会影响该系列后续适用安排。
- “临时例外：单次停课或改时间”仅作用于指定的一次日期。
- 单次例外日期须与该系列原星期一致；当前不能直接把单次课程挪到另一个星期。此类改期需另行核对原次停课与新的单次日程，不能为一周临时变化误改整个系列。

“设置 → 课表”维护时区、教学周编号和明确的 Recess 周。默认可按教学周跳过已登记假期；没有具体假期日期时不会自动猜校历。修改默认设置不直接改写已有课表；选择具体课表后保存才会更新它的规则。

周视图目前没有独立的 Recess 周或教学周标签。空白周既可能是已登记休息周，也可能没有课程，应结合所选课表设置核对。

固定课表、日计划和准备规则使用同一套实际日程。课表本身不自动建立任务、每日计划、出勤或补课反馈。已有准备任务不会因课表改期被覆盖，必要时提示重新核对绑定。

## 准备待办、习惯和提醒

“今天 → 日常习惯”或“设置 → 日常习惯”可查看三类设置：

1. **复盘提醒**：每天/每周提醒时间。提醒出现在软件中；“知道了”只收起提醒，不代填结果。
2. **课前与截止前准备**：围绕日程或截止节点，填写准备内容、完成条件、提前天数和可选估时。
3. **安排偏好**：文字习惯、提前警戒、容量和保护时段。

准备任务先进入指定日期的候选待办，加入日计划后才进入逐项复盘。每次日程独立生成；重复检查不会反复生成同一发生次。节点改期、规则修改或停用，保留已有任务和反馈。新规则从当前业务日开始，后台恢复时按已保存进度有限追补，更早缺口需明确核对。

“自己添加一条偏好”创建文字习惯，供 Codex 在用户请求安排时参考，不表示每句话都有程序硬校验。已有规则可“查看原文 / 修改”。新建容量、保护时段或警戒规则，可到“设置 → 数据与高级 → 高级规则与扩展 → 规则”。

容量和保护时段在计划保存时校验；估时或钟点未知时仍要保留未确认状态。提前警戒只显示风险，不自动创建准备待办。

后台需要本机业务服务运行。关闭管理窗口不等于关闭服务；电脑睡眠或关机期间不会执行。不包含 Windows 登录自动启动或向外部聊天自动推送的承诺。

## 保存资料与整理笔记

打开课程或项目，在“资料与通知”选择“添加资料或通知”，也可拖入文件。支持托管文件、粘贴文字、明确粘贴截图和保存公开网页快照。

默认保存软件管理的副本。相同内容按指纹复用；同名但不同内容另存版本。原文件以后移动或删除，不影响已保存的版本。旧版仅保存路径的引用需要先“保存到软件”，丢失的原件不能凭空恢复。

资料“已保存”与“已完整读取”不同。可以查看提取正文、定位、读取覆盖和警告。PDF、扫描页、常用 Office 文档、文本、邮件正文和图片按支持能力读取；嵌入对象、未处理附件或不支持格式会保留缺口。网页只取公开静态内容，不登录课程平台、不执行网页脚本；需要登录的页面可粘贴正文或截图。

长课件和多页课表采用分批读取与检查点接续，**不再受整份最多8页的旧流程限制**。每批仍有资源和传输预算；大资料可能需要多阶段处理。未读页和解析失败部分不能被当作已读完，也不保证任意文件都能完整解析。

“整理课程信息”从资料中提出课程说明、评分规则、节点和日程候选；“整理课件笔记”使用内置笔记流程，保留来源、概念、例题和未读部分。确认候选后保存。笔记或评分要求本身不自动变成任务，也不等于已经获得成绩或完成学习。

## 两种 Codex 对话

### 软件关联的事项讨论

从每日计划、复盘、课程或其他对象打开的讨论绑定该范围和原业务日期。可在同一个 Codex 会话中继续，候选仍回到原软件事项。标题只是展示，实际归属由保存的关联决定。

有待采用候选时，发送新消息会使旧候选失效；这是为了让新请求使用最新事实。要保留原候选，先核对采用，或明确在下一轮重新提出。新消息不会自动把已保存业务变更撤销。

长任务会分批读取并在原事项、原任务上接续。关闭讨论窗口只停止该窗口的显示和等待，不等于取消已交给桌面的任务。

### 普通项目对话

首次连接后，可从 Codex 的“Codex事务助手”项目进入普通、未绑定软件事项的对话，粘贴通知、邮件或说明希望记录的事情。

普通对话按用户明确要求，可通过 MCP 直接保存已授权的业务变更；只讨论或分析时不保存推测。它与软件共享业务数据，不共享或自动合并全部聊天全文。不能把失效的受管会话当成普通对话绕过确认。

## 中断、取消与恢复

遇到问题先看实时连接状态和本轮处理说明，不必先反复重启两端。

| 情况 | 含义与处理 |
| --- | --- |
| 桌面未连接 | 检查 Codex 是否正常打开和登录，使用“连接 Codex”；已有消息不自动重发。 |
| 正在读取或接续 | 可能仍在分批处理资料或压缩上下文；阶段文字不等于业务已保存。 |
| 超时或发送结果未知 | 保留原任务，先核对原回合和回执，不能直接另发一遍。 |
| 用户明确停止 | 只对已核实的本轮请求尝试停止；远端身份未知时不能保证远端已取消。 |
| “从已保存进度继续”可用 | 沿原操作恢复，不新建同名任务；仍需原身份可核对、没有另一活动任务且数据空间未变。 |
| “恢复原会话关联” | 用于已存在原会话的关联核对；不是普通连接按钮，也不是任意选择一个同名会话。 |

并非所有失败或取消都可恢复。缺少可靠身份、检查点失效、相关资料已变或原回合仍未确认结束时，应按提示核对。取消后的迟到结果不会自动采用；显式恢复会创建新的处理代次，旧回调不能覆盖新进度。

## 文件夹、备份与恢复

课程或项目的“打开文件夹”可查看软件管理的可浏览原件；设置的数据页提供“打开原文件目录”。原件副本默认只读。另存或编辑后，需通过“添加资料或通知”重新导入才成为新的业务资料版本。

“设置 → 数据与高级 → 创建并核验备份”备份业务数据库和已登记的托管版本。仅存外部路径的引用不等于备份了外部文件；没有导入软件的额外文件也不在托管备份范围内。

“恢复备份到新目录”保留当前空间，写入新的空目录。恢复后的数据身份变化，旧候选失效，定时和固定准备配置暂停，需核对后重新启用。重新打开恢复目录并检查 Codex 连接，不能把旧空间的会话关联直接当成新空间已经连接。

## 外观与其他边界

“设置 → 显示”可调整主题、字体、字号和周统计图样式。缺少原字体时会使用替代字体，保留原保存选择。项目目录可收起或展开。

高级文档成果生成、成果版本和采纳接口主要供 MCP 或开发接入，当前没有覆盖全部成果流程的独立 GUI。登录平台抓取、完整邮件账号同步、任意格式无损解析和自动跨日最优排程也不属于本版承诺。

v1.0.0 基于已冻结功能发布，用户已完成日常使用体验验收。该结果不代表所有场景清单、全部硬件组合和长期稳定性都逐项验证。
