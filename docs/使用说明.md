# 个人事务管理 0.7 使用说明

## 第一次使用

双击项目根目录的“启动个人事务管理.vbs”。日常入口仍是今天、项目与课程、复盘。软件没有迁移 D:\Y2S1，之前试用时保存的记录保留。

## 建立课程、项目和任务

每类事项有自己的创建窗口。课程填写课程名称和可选代码，项目填写目标与验收条件，活动填写活动信息，任务填写归属和完成标准。

课程、项目、活动默认独立建立。“分类”是可选的长期整理方式，例如学习、健康、职业；它是原来“领域”的新名称，不是另一门课程。需要时再勾选分类。任务可以属于课程或项目；在项目中建立子项目时，会明确显示父项目。

课程的“学期与更多信息”中可以补充第一教学周周一和学期结束日期。没有填就保持未知；软件不会猜测第几周对应的日期。

## 上传整周课表，建立每周框架

在“今天”点“每周课表” → “导入课表”。只需三项：选择课表图片/PDF（按钮右侧箭头可以粘贴截图）、给课表起名、选择适用范围。点“整理课表”会保存软件副本并进入 Codex 讨论，识别完成后核对候选并确认。原文件移动或删除不影响已保存副本。Excel课表先导出PDF或截图。

起始范围选择第一教学周；选择该周中任一天会显示对应周一，结束日包含在范围内。周视图按实际日期显示已确认课程，日常只保留日期导航和导入；表名旁“⋯”中可以管理已有课表、手动添加时段或查看停用的时段。点击课程格子编辑该系列及单次停课/调时。不连接 Codex 也可手动建立框架。

时区与假期在“设置 → 课表”。新课表默认 Recess week 不计入教学周；请按校历加入明确的假期周。比如第7教学周后休息一周，随后继续第8教学周，单双周课程据此安排。假期本身不安排课表课程。默认设置可保存多个学期的日期，导入时只取所选范围内的日期。

已有课表不因默认设置变化就自动改周号。在设置上方选择具体课表，再保存，会统一更新它的实际固定时段。旧版按日历周保存的课表会保留原含义，确认改成教学周后才跳过假期。已经生成的准备任务及历史记录保留，必要时提示重新核对绑定。

相同名称和适用范围再次上传会复用已有课表，保留已确认的设置。新资料整理时核对原时段，不重复创建；未列出的旧时段也不会直接删除。所有课时与每日计划共用日程数据，生成每日计划时避开固定课程。课表不会自动创建任务、补课事项、每日计划或完成反馈。

课表PDF同时读取文字和布局，每次最多8张图片/页；超过需要拆分。复杂班别、模糊格子和时间冲突保留待确认，不自动选班、猜日期或挪课。

## 删除测试或不再需要的任务

点开任务，在详情下方点“删除任务”；编辑任务窗口也提供这个入口。确认后任务会从课程任务列表和待办候选中移除，成功页可立即“撤销删除”。

删除保留原计划、反馈与关联证据。历史计划中的条目显示“已删除”，不会继续要求复盘或接受新反馈；恢复后可以继续操作。有未处理子项时会提示先处理，不会连带删除。

“今天”右上方的“手动安排”使用明显边框和加粗文字，可直接自己安排；“让 Codex 安排”是自然语言协助入口。

## 字体、深色模式与目录

设置 → 显示，可以选择本机字体、字号和浅色/深色主题。深色使用中性灰黑背景、白色文字和蓝色强调色。保存后已打开窗口跟随更新；浅色默认保持原来风格。换电脑缺少原字体时会明确使用替代字体，不改写原保存选择。

项目与课程的“项目目录”右上可收起，收起后保留“展开目录”按钮；当前选中课程和保存偏好保留。

## 课程记录的编辑与含义

实际任务是要执行的具体工作，不表示已经排入某天。“交付与重要日期”记录明确交付、截止日或阶段检查点。一般课程参与要求应保存在课程说明或笔记，不能凭此自动建立周期任务。

此前已保存的记录保留来源。未明确日期的节点显示编辑说明与日期入口，不再处处显示准备规则；一次性节点是“截止前准备”，重复日程才是“每次提前准备”。日程、评分、任务、笔记和节点都可从对应条目编辑；后台与外部Codex的update接口同样可用。只读或归档对象的边界仍受业务校验。

## 补课与补欠

每门课程有“补课与补欠”。点“登记补课 / 补欠”，写需要补的范围、完成条件、计量单位及已知数量。例如总量8节课、累计已补3节；未知可以留空。也可复用本课程已有任务，保留原编号及记录，不额外创建第二个任务。

“记录补欠进度”记录累计已补量，并可单独明确已完成或未完成全部条件。数字达到8/8不会自动声明掌握、提交或到课。降低或清除旧数量需选择更正并说明原因，历史反馈保留。“加入某天计划”沿用普通任务流程，排入日计划后进入当日复盘。未到课、日期过期或缺少反馈不会自动被算成欠课。

也可以在课程讨论里说：“我落下了8节，目前补了3节，请登记补课，完成条件是补完课程并完成对应练习。”Codex提出候选后核对保存。

## 用会话整理课件笔记

先在课程添加课件，再点“整理课件笔记”，或在课程讨论里直接说“这是这门课的课件，整理笔记”。软件会使用打包的course-notes技能，依据实际读取的内容整理概念、公式、适用条件、例题和闭卷自测，标明来源及未读部分。笔记正文在讨论中查看，需要保存时核对候选。

课程首页只保留简短的笔记标题与摘要，可以打开阅读、继续在Codex中整理或手动编辑。笔记整理不会自动建立任务、里程碑或完成反馈。外部Codex也安装了同名技能，可使用 `$course-notes`；新会话能发现已安装技能。软件内会话不依赖外部会话读取该技能。

## 把资料和新信息交给课程

打开课程或项目，在“资料与通知”中点“添加资料或通知”，也可以拖入文件。

- 文件：课件、PDF、Word、PowerPoint、文本、邮件文件等。
- 文字：直接粘贴临时通知或邮件正文，可以补一个便于识别的名称。
- 截图：复制截图后，在添加窗口明确选择粘贴截图。
- 网页：粘贴公开网页链接，保存本次取得的静态正文快照。

**默认保存软件管理的副本。** 原件之后移动、改名或删除，已保存的版本仍可用。相同文件内容按指纹复用，不反复存一份相同大文件。原件更新后需要重新添加，形成新的内容版本；不会悄悄覆盖已经采用的依据。

旧版只保存路径的文件会明确显示为引用。选择“保存到软件”后才能获得副本保护；已经丢失的旧原件不能凭空恢复。

资料会显示实际读取状态。可预览提取正文、来源、读取页数和警告，也可以打开保存版本。读取失败或格式不支持时仍保存原件，不能把“已保存”理解成“Codex已读懂”。

目前支持 PDF文字及扫描页图片、DOCX/PPTX文字与备注、普通文本、.eml邮件正文和图片。Office内嵌图表、未读取的邮件附件会明确提示；重要图表可另附截图。.msg、老式Office或其他未支持格式仍可保存，但需另存PDF/.eml或粘贴正文才能自动整理。

网页不读取登录账号、不运行脚本。需要登录的课程平台、内网页面或动态内容，使用粘贴正文或截图。网页快照默认以安全正文预览，不运行原网页脚本。

## 一键整理课程信息

先添加课程介绍、评分说明、日程或通知，再点“整理课程信息”。配置正常时会直接开始读取并讨论，不用逐项手建。

Codex 会提出原文已有的评分组成与权重、截止节点、固定日程、每周安排等。课程页会显示保存后的评分规则和安排。评分权重不等于实际成绩；资料没有写明的日期、时间、学期锚点和规则会留待确认。

先核对回复下面的候选与来源，再点确认保存。同一课程的同名同值内容会复用；同名但内容不同需要明确更新，不能悄悄新增重复定义。一次候选最多30项，大范围课程信息需要分批核对。

## 与 Codex 讨论

界面是自动保存的连续讨论：中间为消息，底部为输入框、附件和发送。Enter发送，Shift+Enter换行；处理中可停止。

同一天的计划调整自动回到同一段计划讨论，同一门课程也自动回到自己的讨论。无需复制问题到外部对话，也不需要按“继续上次讨论”。新消息会重新读取当前业务事实；旧候选不会覆盖新事实，继续讨论后旧候选不能再被采用。

附件可以在输入框上方移除，移除只改变后续讨论参考范围，不删除资料。每轮最多12份资料、8张图片；超过正文或解析预算时会明确提示分批，不会默默截断后宣称已读全。

尚未启用时，讨论窗口只引导“连接 Codex”。在设置中启用本机Codex，并确保已登录。界面不会复制或导出账号凭据。普通手动记录与复盘不依赖模型。

外部Codex仍可以通过设置中的MCP配置操作同一数据空间，新对话先读取当前状态。软件内讨论和外部Codex聊天是两个界面，共享的是业务记录，软件不会自动向某个已有外部聊天发送消息。

## 任务、截止节点与固定准备事项

课程页将“实际任务”“截止节点与成果”“知识点与笔记”分开。评分规则解释课程如何计分，笔记保存要求；它们本身不会自动变成今天必须执行的任务。

今天页的“当天候选待办”只显示已指定日期、当天到期或此前仍未处理的任务。未指定日期的其他任务仍在项目或课程中。点击“加入这天计划”，或者打开任务详情选择日期后加入，才会进入那天的逐项复盘。新建的计划默认不猜具体时间；原有计划会保留。重复点击不会重复加入，休整日需要先明确调整计划。

在日程或截止节点旁点“固定准备事项”，填写准备内容、完成条件、提前天数及可选估时。例如每周实验课前两天出现“完成课前练习”。也可以在与 Codex 讨论中直接说明要求，核对其规则候选后保存。新建日程与绑定规则分两步：先保存日程，再继续让 Codex 设置准备规则。

规则跟随节点的重复频率，每次生成独立任务，先成为相应日期的候选待办，不自动排计划、不自动打勾。节点缺少明确日期时不会生成；改期、停用或修改规则会保留已有任务并提示核对，不覆盖执行反馈。确认重新绑定只影响后续生成。服务运行时生成当前业务日的准备事项；重新启动时会按上次处理进度补齐漏过的日期，最多追补31天，更早的缺口会提示核对。新规则从当前日开始，不自动建立过去的任务。电脑关机期间不运行；更早日期可通过 Codex 明确分批补齐（每次最多31天）。

## 模型选择与资料依据

设置 → Codex 的模型改为下拉选择，列表来自本机 Codex，可手动刷新。“跟随本机 Codex 设置”保留本机配置；读取失败或原模型不在列表中时保留原选择，不偷偷更换。列表刷新不发起AI对话。

软件内讨论使用软件提供的当前记录、所选附件及该范围的讨论历史；后台配置禁用个人记忆读取，且不开放文件、网络和外部工具。每次资料整理仍需核对来源页码、读取覆盖和未知项。来源不全时，旧聊天和模型常识不能补成已确认的课程事实。

## 今天、复盘与图表

今天显示每日计划、固定安排和提醒。可以让Codex生成或调整计划，也可以手动选择任务安排。

每日复盘按计划逐项选择完成或未完成，未选保持未反馈。反复读取和相同结果保存不新增重复反馈；到课、提交、掌握和实际用时不由完成状态推断。没有明确计划时，可在连续讨论中按实际情况复盘。

每周回顾默认使用等高纵向柱形图：每天都是100%高度，内部颜色显示完成、未完成、未反馈和已有细分反馈。缺计划、空计划单独显示，不算0%失败；柱下保留任务项数，比例不是工作量或掌握程度。

设置中的“显示”可以改用横向进度条。日期选择器可展开完整月份选择日期。

## 提醒、备份与恢复

设置首页可启用每日复盘时间、每周回顾的星期与时间。提醒出现在今天页；“知道了”只收起提醒，不代表完成。电脑关机期间不运行，尚未安装系统登录自动启动，也不向外部Codex聊天自动推送。

备份包含业务数据库、已托管的原件和可读取的衍生内容；旧路径引用仍只备份路径。恢复到新目录，保留当前数据。恢复后旧候选失效，原定时任务和固定准备规则暂停，软件内讨论保留但会重新建立模型连接。

遇到另一端改动造成的冲突，请保留当前输入并重新核对。写入连接中断时先查原回执，避免手动创建重复事项。
