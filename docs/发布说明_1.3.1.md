# 个人事务管理 1.3.1

将本地 Beta 的主题与易用性 A 阶段改动同步到正式版，继续使用原正式数据与连接配置。

## 界面与操作

- 提醒、复盘选中项和图表跟随强调色；未反馈保留中性色，错误和删除操作使用独立提示色。课程进度条加粗，进度增加轻微渐变和首次显示动画，计数、结果含义及减少动画偏好保持不变。
- 任务入口先显示快速记录和本次最近记录，完整任务库单独进入；返回保留筛选、排序、选择和滚动位置。任务排序在后台完成后再分页。
- 批量记录分为输入、逐项核对与保存结果；拆分任务有独立的完成标准和子任务说明。记录成功后可查看或送入计划草稿，不自动安排。
- 截止日期和预计用时采用紧凑展开入口，所属位置显示完整路径；空值、零值、清除和扩展字段原值分别保留。
- “今天”页在宽窗并排显示警戒和任务，窄窗上下排列；警戒分类计数后分页，并可快速添加任务或选择已有任务加入当天。
- 保存状态更明确，未知结果沿用原请求核对，未完成保存和未保存输入受到退出保护；托盘退出和准备更新也会在停止后台前检查主页面输入及待核对回执。教程同步至新入口。

## 更新

更新前保存编辑并等待任务结束。新版继续使用原正式数据空间，升级前自动保留数据库快照；不重新导入资料，不改变完成记录，不迁入 Beta 演示数据。

软件、后台与 MCP 使用 1.3.1 / stable。旧 Codex MCP 连接需在空闲后刷新。本地程序与安装包位于 `release/PersonalManagement-1.3.1/`，1.3.0 原产物保留。

本次未增加新的助手供应商或跨多天计划的原子保存能力。验证事实与限制见开发交接文档。
