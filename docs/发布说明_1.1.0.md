# v1.1.0 保留数据的版本升级

本次更新补齐安装升级与运行中版本核验，延续 1.0.2 的双客户端接口修复。

- 安装器记住数据位置，兼容读取旧快捷方式；升级替换已登记的程序目录，继续使用原数据库、资料和附件。不能确认旧数据位置时要求选择，静默安装可用 `/DATADIR=绝对路径` 明确指定。
- 主窗口新增“版本与更新”，展示软件、后台及最近一次 MCP 请求的版本。旧入口连接新版后台会明确被拒绝，不再以连通代替接口版本一致。
- 新增“退出并准备更新”。等待读取、保存、资料处理和后台任务结束后正常退出服务，暂停自动拉起；重新打开管理软件可取消准备状态或继续更新后的使用。
- 旧数据库升级前保存经过完整性核验的数据库快照，结构更新以事务完成。快照失败不进行迁移；迁移失败回滚。程序不会自动恢复旧快照覆盖后续资料。
- 保留原数据位置、业务 ID、计划历史、反馈、设置及会话关联；资料文件不搬移，不要求重新导入。升级快照明确是数据库快照，完整业务备份仍使用已有备份功能。

安装器更新需要释放正在使用的程序文件。若 Codex 的 MCP 仍占用旧程序，需在任务结束后暂时退出 Codex。1.0.x 首次升级仍需先退出旧后台；1.1.0 起提供正常准备更新入口。旧便携目录不会被安装器清空，新安装版可直接选用其原数据目录。

本版不提供在线自动下载更新，不承诺所有 Codex 已打开会话的接口自动热刷新。一次新版 MCP 调用核验成功，只证明该次调用；其他旧会话仍可能需要重新加载。
