# v1.0.2 本地修复包

本包包含双客户端交接扫描中九项高优先级修复，并明确当前计划接口。安装包已构建不等于正在运行的服务和 Codex MCP 已经更新；本地切换后须分别核对实际执行程序与工具能力。

## 修复内容

- 核对选定数据目录与发现文件、服务状态的实际归属，拒绝错误连接文件导致的跨数据空间访问。
- 普通事项和独立作业统一核对真实回合与处理代次；旧回调不能覆盖恢复后的检查点或候选。
- 原生候选保存后遇到超时等异常，继续只读核对原回合终态，不提前结算或重复派发。
- 课程候选在校验和采用时共同检查目标范围；显式不选资料不解除课程限制，全日休整与无归属的空计划由每日计划入口处理。
- 专用 MCP 保存计划工具正确接收整数分钟；大对象、回执、记录列表与资料正文保留原查询含义并支持有版本的完整续读。
- `today` 显式返回 `current_plan_id` 和 `current_plan_version`，历史列表首项不代表当前版；大响应也保留当前计划身份。

这些修复已在隔离数据上完成分组全仓库验证：2031 项通过、11 项子测试通过，3 项因本机无法创建目录符号链接而跳过。首次单进程 GUI 测试停滞未计为通过；相关文件独立运行 12 项通过，其余仓库测试在另一个进程完成。打包后的验证记录另行保留。

## 本次不包含

原扫描中的十三项次优先问题仍保留，包括累计订阅释放、部分取消与恢复展示、完整版本协商，以及其他未覆盖的长结果读取分支。本包不新增区间排程或任务拆分窗口。

## 已有数据的本地更新

继续使用原数据目录，保留原计划修订链、反馈和会话关联。更新前保留数据库及受管理配置备份；存在正在执行的任务时不切换后台服务。管理界面、业务服务和项目 MCP 都需要使用本包，单独打开新版界面不会替换已在运行的旧服务或 MCP。

本说明描述本地修复包，不代表已经创建远端 Release。
