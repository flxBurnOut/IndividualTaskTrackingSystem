# 个人事务管理

当前已有可运行的 Windows 原生版本（0.7）。界面、Codex 接口和后台推理共用独立本机业务服务及 SQLite 数据库；不需要 npm 或网页前端编译。

**本次只构建软件，没有迁移 `D:\Y2S1`；发布包不带业务数据，试用时已保存的记录保留。** 测试仅使用隔离的合成记录。完整历史功能方案仍有后续工作，具体见 [功能实现对照](docs/功能实现对照.md)，不能把本版当成全部 49 类场景已验收。

## 启动

- 项目内使用：双击 `启动个人事务管理.vbs`。它使用本目录下的 `data` 数据空间。
- 便携软件：打开 `release/PersonalManagement-0.7/PersonalManagement.exe`。默认数据位于 `%LOCALAPPDATA%/PersonalManagement/data`。
- 切换/恢复后的数据空间：使用软件目录中的 `选择数据空间.vbs`，选择整个数据目录。
- Codex 入口：在软件设置中复制当前数据空间的接口配置，加入 Codex 的 MCP 配置后在新对话使用。软件不会自行修改你的 Codex 配置或复制账号。

请保持软件包文件夹完整，不要只单独复制其中一个 exe。移动软件不会自动移动业务数据；数据空间可通过备份恢复到新目录。

[使用说明](docs/使用说明.md) · [Codex 接入与推理边界](docs/Codex接口与后台推理.md) · [开发与扩展](docs/开发与扩展.md) · [实施验收记录](实施验收记录.md)

日常入口为“今天、项目与课程、复盘”。每日复盘逐项选择完成或未完成，未选保持未知；资料随所属项目保存受管理副本；支持课件、通知、邮件、截图与网页，并可让Codex整理课程信息。复盘时间在设置首页。
